# 掲示板の感情分析 (/sentiment)

`/sentiment <銘柄コード>` で、Yahoo Finance 掲示板の直近の投稿を読み、感情ラベルの分布と材料をまとめる。結果は会話に表示するだけで、保存しない (issue #62)。

モデルは Sonnet に固定している (frontmatter の `model`)。モデルが変わると判定の基準がぶれ、日をまたいだ温度の比較ができなくなるため。

## 手順

1. 投稿を取得する (新しい順に50件)

   ```bash
   cd scripts && ../.venv/bin/python sentiment.py <銘柄コード>
   ```

   「投稿を取得できませんでした」と出たら、その旨を伝えて終わる (HTML 形式の変更は `pytest tests/test_live_html.py -k Forum` で確かめる)。

2. 投稿1件ずつに、下の表からラベルを**1つだけ**付ける。迷ったら、書き手が今どういう衝動で書いているかで選ぶ。銘柄と無関係な投稿 (雑談・荒らし・他銘柄の宣伝) と、投稿者どうしの罵り合いはラベルを付けず、件数から除く。罵り合いは件数だけ数えておく。

3. 下の「掲示板の温度」の計算で7段階に読み替える。

4. 「出力」の形式で表示する。

## 感情ラベル (8種)

| ラベル | 判定の基準 | 投稿の例 | 点 |
|---|---|---|---|
| 熱狂 | 上がると決めつけ、疑う人を見下す。根拠のない目標株価 | 「テンバガー確定」「売る奴はバカ」 | +2 |
| 期待 | 上がると見ているが、根拠や時期に触れている | 「決算楽しみ」「ここから上」 | +1 |
| 焦り | 乗り遅れを恐れて買いたがっている | 「乗り遅れた」「今から買っても間に合う?」 | +1 |
| 冷静 | 業績・材料・需給の分析、情報提供。売買の衝動が見えない | 「自己資本比率70%で利上げの影響は小さい」 | 0 |
| 不安 | 下がる心配、悪材料への疑い | 「大丈夫か」「増資あるかも」 | −1 |
| 怒り | 経営・機関・空売り・信用買い勢など、株価を動かす相手への不満 | 「IR 何やってる」「機関の売り崩し」 | −1 |
| 落胆 | あきらめ、塩漬け、損切りの報告 | 「塩漬け」「もう見ない」「損切りした」 | −2 |
| 恐怖 | 底が見えない下げへのおびえ、投げ売り | 「どこまで下がる」「全部投げた」 | −2 |

皮肉・自嘲は字面ではなく本心で選ぶ (下落局面の「絶好調ですね笑」は怒りか落胆)。

投稿者どうしの罵り合い (特定の投稿者への人格攻撃、煽り、その応酬) は「怒り」にしない。株への感情ではなく、強気派が弱気派を罵る投稿まで恐怖側に数えてしまうため。罵りの中に銘柄の材料や見通しが書かれていれば、その中身でラベルを付ける。

## 掲示板の温度 (7段階)

ラベルの点の平均を、感情スコアシート (`doc/投資戦略.md` の「感情スコアとレバレッジ」) の7段階に読み替える。

| 平均 | 温度 | 状態 |
|---|---|---|
| +1.25 以上 | +3 | 過信・熱狂 |
| +0.75 以上、+1.25 未満 | +2 | 興奮・楽観 |
| +0.25 以上、+0.75 未満 | +1 | やや強気 |
| −0.25 より上、+0.25 未満 | 0 | 中立・冷静 |
| −0.75 より上、−0.25 以下 | −1 | 弱気・不安 |
| −1.25 より上、−0.75 以下 | −2 | 怖いがまだ冷静 |
| −1.25 以下 | −3 | 極度の恐怖 |

投稿の期間が2週間を超えるときは、全体の平均は今の温度を表さない。**直近10件だけの温度も同じ表で出して併記する**。

投稿の期間が1時間に満たないときは、その瞬間の値動きへの反応しか映らない。**見出しの直後に「⚠ 標本は {N}分間です。その瞬間の熱で、板の普段の空気ではありません」と1行で警告する**。

## 出力

```
## 掲示板の感情分析: {銘柄名} ({コード})  投稿 {N}件 ({最古の日時} 〜 {最新の日時})
⚠ 標本は 3分間です。その瞬間の熱で、板の普段の空気ではありません  (期間が1時間未満のときだけ)

### 掲示板の温度
+2 (興奮・楽観) 相当  ※平均 +0.84
直近10件: −1 (弱気・不安) 相当  ※平均 −0.40  (期間が2週間を超えるときだけ)

### 感情の分布
貪欲側 52% / 中立 24% / 恐怖側 24%
期待 48% (12) / 冷静 24% (6) / 不安 16% (4) / 怒り 8% (2) / 熱狂 4% (1)
ほかに罵り合い 22件  (5件以上あるときだけ)

### 主な感情
- 期待 (12件): 8/14「(代表的な投稿を1件引用)」👍18 👎0
- 冷静 (6件): 8/20「(代表的な投稿を1件引用)」👍13 👎0

### 読み手の反応
- 支持: 8/14「(投稿を引用)」👍19 👎0
- 反発: 9/13「(投稿を引用)」👍2 👎15

### 要約
- (2〜3行)

### 材料
- (強気) ... (9/14 👍13 👎1)
- (弱気) ... (9/13 👍2 👎15、同意は少なめ)
```

- **引用には必ず日付と反応を付ける**。日付は前に月/日だけ (時刻と年は書かない)、反応は後ろに 👍 (そう思う) 👎 (そう思わない) と数字。票は古い投稿ほど溜まるので、日付が無いと反応の重みを読めない

- 感情の分布は割合で出す。1行目は3分類 (貪欲側 = 熱狂・期待・焦り / 中立 = 冷静 / 恐怖側 = 不安・怒り・落胆・恐怖)、2行目はラベル別に多い順で、件数を括弧に添える。0件のラベルは書かない。割合の母数はラベルを付けた投稿だけ。除いた罵り合いが5件以上あれば、3行目に件数を書く (板が荒れていること自体は情報なので残す)
- 主な感情は上位2つ。代表的な投稿は「そう思う」が多いものを優先し、長ければ要所だけ引用する
- 読み手の反応は「そう思う」「そう思わない」から選ぶ。書き込まない多数の反応なので、本文とは別の情報になる
  - 対象は票 (そう思う + そう思わない) が5以上ある投稿だけ。古い投稿ほど票が溜まるので、絶対数ではなく割合で選ぶ
  - 支持は「そう思う」の割合が最も高い投稿、反発は「そう思わない」が「そう思う」を上回る投稿のうち差が最も大きいもの。各1件 (目立つものが複数あれば2件まで)。反発が無ければ「反発: 目立つものなし」と書く
  - 反発された投稿の向きに触れる (弱気の意見が反発されているのか、強気の意見が反発され始めたのか)
- 材料は各項目に強気/弱気の向きを付ける。投稿に出てきたものだけを書き、自分の知識で補わない。各項目の末尾に、元になった投稿 (複数あれば代表の1件) の日付と反応を括弧で添え、反応が割れている・同意が少ない材料にはその旨も書く
- 「投稿者の選択」は、投稿者自身が任意で選ぶ投資スタンス。付いている投稿は少ないので温度や分布には使わず、5件以上あるときだけ末尾に1行で内訳を添える。偏りがあれば (時間帯で買いたい側と売りたい側が入れ替わる、強気の選択が罵り合いの投稿に集中している等) 同じ行に一言添える。値の対応は `strongest` = 強く買いたい / `strong` = 買いたい / `both` = 様子見 / `weakest` = 強く売りたい (投稿の内容からの推定。「売りたい」の値は未確認で、おそらく `weak`)

## 読み方の注意 (出力の末尾に1〜2行で添える)

- 掲示板は強気に偏る (書き込むのはホルダーが中心)。「期待」が多いのは普通の状態で、見るのは熱狂・落胆・恐怖といった端のラベルが出ているか
- 投稿の期間が長い (数週間〜数か月) 銘柄は、全体の温度と直近10件の温度の差に触れる
- 売買の根拠にはしない。定性的な材料として読む
