# 掲示板の感情分析 (/sentiment)

`/sentiment <銘柄コード>` で、Yahoo Finance 掲示板の直近の投稿を読み、感情ラベルの分布と材料をまとめる。結果は会話に表示するだけで、保存しない (issue #62)。

## 手順

1. 投稿を取得する (新しい順に50件)

   ```bash
   cd scripts && ../.venv/bin/python sentiment.py <銘柄コード>
   ```

   「投稿を取得できませんでした」と出たら、その旨を伝えて終わる (HTML 形式の変更は `pytest tests/test_live_html.py -k Forum` で確かめる)。

2. 投稿1件ずつに、下の表からラベルを**1つだけ**付ける。迷ったら、書き手が今どういう衝動で書いているかで選ぶ。銘柄と無関係な投稿 (雑談・荒らし・他銘柄の宣伝) はラベルを付けず、件数から除く。

3. 下の「掲示板の温度」の計算で7段階に読み替える。

4. 「出力」の形式で表示する。

## 感情ラベル (8種)

| ラベル | 判定の基準 | 投稿の例 | 点 |
|---|---|---|---|
| 熱狂 | 上がると決めつけ、疑う人を見下す。根拠のない目標株価 | 「テンバガー確定」「売る奴はバカ」 | +2 |
| 期待 | 上がると見ているが、根拠や時期に触れている | 「決算楽しみ」「ここから上」 | +1 |
| 焦り | 乗り遅れを恐れて買いたがっている | 「乗り遅れた」「今から買っても間に合う?」 | +1 |
| 冷静 | 業績・材料・需給の分析、情報提供。売買の衝動が見えない | 「自己資本比率70%で利上げの影響は小さい」 | 0 |
| 不安 | 下がる心配、悪材料への疑い | 「大丈夫か」「増資あるかも」 | −1 |
| 怒り | 経営・機関・空売り・他の投稿者への不満 | 「IR 何やってる」「機関の売り崩し」 | −1 |
| 落胆 | あきらめ、塩漬け、損切りの報告 | 「塩漬け」「もう見ない」「損切りした」 | −2 |
| 恐怖 | 底が見えない下げへのおびえ、投げ売り | 「どこまで下がる」「全部投げた」 | −2 |

皮肉・自嘲は字面ではなく本心で選ぶ (下落局面の「絶好調ですね笑」は怒りか落胆)。

## 掲示板の温度 (7段階)

ラベルの点の平均を、感情スコアシート (`doc/投資戦略.md` の「感情スコアとレバレッジ」) の7段階に読み替える。

| 平均 | 温度 | 状態 |
|---|---|---|
| +1.25 以上 | +3 | 過信・熱狂 |
| +0.75 以上 | +2 | 興奮・楽観 |
| +0.25 以上 | +1 | やや強気 |
| −0.25 より上、+0.25 未満 | 0 | 中立・冷静 |
| −0.25 以下 | −1 | 弱気・不安 |
| −0.75 以下 | −2 | 怖いがまだ冷静 |
| −1.25 以下 | −3 | 極度の恐怖 |

投稿の期間が2週間を超えるときは、全体の平均は今の温度を表さない。**直近10件だけの温度も同じ表で出して併記する**。

## 出力

```
## 掲示板の感情分析: {銘柄名} ({コード})  投稿 {N}件 ({最古の日時} 〜 {最新の日時})

### 掲示板の温度
+2 (興奮・楽観) 相当  ※平均 +0.84
直近10件: −1 (弱気・不安) 相当  ※平均 −0.40  (期間が2週間を超えるときだけ)

### 感情の分布
期待 12 / 冷静 6 / 不安 4 / 怒り 2 / 熱狂 1

### 主な感情
- 期待 (12件): 「(代表的な投稿を1件引用)」
- 冷静 (6件): 「(代表的な投稿を1件引用)」

### 要約
- (2〜3行)

### 材料
- (強気) ...
- (弱気) ...
```

- 感情の分布は件数の多い順。0件のラベルは書かない
- 主な感情は上位2つ。代表的な投稿は「そう思う」が多いものを優先し、長ければ要所だけ引用する
- 材料は各項目に強気/弱気の向きを付ける。投稿に出てきたものだけを書き、自分の知識で補わない
- 「投稿者の選択」(強く買いたい〜強く売りたい) が付いた投稿が5件以上あれば、末尾に1行でその内訳を添える

## 読み方の注意 (出力の末尾に1〜2行で添える)

- 掲示板は強気に偏る (書き込むのはホルダーが中心)。「期待」が多いのは普通の状態で、見るのは熱狂・落胆・恐怖といった端のラベルが出ているか
- 投稿の期間が長い (数週間〜数か月) 銘柄は、全体の温度と直近10件の温度の差に触れる
- 売買の根拠にはしない。定性的な材料として読む
