# テーマ急上昇ニュース調査

market_data.html の上位3テーマについて、急騰・急落の理由を WebSearch で調査し推察する。要約をデイリー保存し直近1ヶ月分を次回コンテキストに使う。

## 基本方針

**「アクター × シグナル」で網羅的に洗う**。テーマ名そのままのクエリだけだと必ず見逃す。発信者（アクター）は限られており、各アクターを1回以上検索すれば取りこぼしを構造的に防げる。**1クエリに複数アクターを混ぜると有名な1件に引きずられる** ので、アクター別に独立で検索する。

### アクター階層（株価インパクトが大きい順）

1. **政治**: 首相・担当大臣・与党幹部・閣議
2. **行政**: 担当省庁・審議会・検討会
3. **海外**: 海外政府の類似政策、関税、地政学、同業国動向
4. **企業**: 個別決算・業績修正・提携・受注・新製品
5. **相場**: 地合い、セクターローテーション、資金フロー

### シグナル語彙（クエリに織り込む汎用語）

時代・政権が変わっても機能する具体名を含まない語:

- **介入**: 「国が前に出る」「全面支援」「基幹戦略」「経済安保」
- **制度変更**: 「法改正」「閣議決定」「行動計画」「規制緩和/強化」
- **数値コミット**: 「◯兆円」「◯年まで」「◯%目標」
- **公人発言**: 「表明」「発言」「会見」「指示」
- **国際連動**: 「米国/中国/EU」「関税」「輸出規制」

## 手順

### 1. 過去履歴の読み込み

`.claude/skills/theme-news/history/*.md` を Glob し、ファイル名 `YYYY-MM-DD.md` で **今日から30日以内** のものだけ Read。テーマの継続性・推移把握に使う。存在しなければスキップ。

#### 1-1. 履歴の日付ギャップ検出

履歴最新日と今日の差で分岐:

- **前営業日あり、または1営業日のみ欠落**: 通常通り。手順4の「直近1週間」検索で自然にカバーされる
- **2営業日以上欠落**: 手順4で空白期間カバー検索を追加
- **3営業日以上欠落 / 初回実行**: 直近1週間を遡及検索

### 2. テーマランクデータの読み取り

`$KS_DATA_DIR/code_rank_data/market_data.html` を解析:

- `<h2>テーマランク</h2>` 後の `<div class="theme-grid">` 内 `<div class="theme-badge ...">` から、ランク・テーマ名・騰落率・前日比ランク変動（**↑N / ↓N / → / NEW**）を取得
- 上位3テーマ（#1〜#3）が調査対象
- **NEW** = 前回ランキング外からのランクイン。注目すべき新興テーマで「急上昇」候補

#### 前提: market_data.html のデータ仕様

- **生成**: `make_market_db.py` を 18:00 以降に手動実行（=当日生成）
- **基準時点**: 株探テーマランクは土日祝も数時間ごと更新されるため、騰落率・ランク変動は「直前更新時点のスナップショット」
- **整合性チェック**: テーマ騰落率と日経当日比に乖離（例: 日経+1%でテーマ-1%）があれば、まず「セクターローテーション」、次に「別時点スナップショット」を疑う。両論併記してよい
- **土日祝**: market_data.html の日付をそのまま当日扱い。整合性チェックの比較先は **直前営業日の日経・TOPIX終値、当日のADR/夜間先物**（ADR等が拾えなければ夜間先物または週間レビューで代替可）

### 3. 市場全体の重要ニュース調査（マクロ）

テーマ別調査の前に市場全体を動かしうるマクロ材料を押さえる。各テーマの相対評価の基準になる。

以下のカテゴリを最低1回ずつ検索:

- **M1. 国内政治・政策**: 政権・首相・大臣の動き、大型政策パッケージ、補正予算
- **M2. 米国マクロ**: 大統領発言、関税、FOMC・利下げ、米財政
- **M3. 地政学**: 戦争開始/停戦、領土紛争、サイバー攻撃などリスクオン/オフ転換点
- **M4. グローバル決算**: 米巨大ハイテク（AI/半導体/クラウド）の決算・ガイダンス
- **M5. 為替・金利**: ドル円、日銀政策、長期金利、原油・金
- **M6. 国内市況**: 直前営業日の日経・TOPIX終値、業種別騰落、ADR・夜間先物（取得元は market_data.html ではなく WebSearch。ADR等の個別値が拾えない場合は夜間先物・週間レビュー等の代替指標で補完すれば可）

検索結果から、**継続中の大型材料**・**直近の転換点**・**地合いの分類**（リスクオン/オフ/一極集中）を整理。手順5の推察で個別テーマと突き合わせる比較対象になる。

### 4. テーマ別ニュース検索（アクター網羅）

各テーマで**アクターA〜D を最低1回ずつ**検索（A=政治/B=行政/C=海外/D=企業）。1テーマあたり3〜4回想定。アクターE（相場）は手順3を流用、追加検索不要。

#### 4-1. 類語展開

検索前にテーマ名の類語を2〜3個挙げる。テーマ名そのままだと公的文書・正式名称にヒットしないことが多い。

- カタカナ↔漢字の公式用語
- 略語↔正式名称
- 業界用語↔一般語
- 周辺技術・上位/下位概念

思いつかなければ `"{テーマ名}" 関連銘柄 別名 OR 正式名称` で1回引き出す。

#### 4-2. アクター別検索

クエリは **テーマ名or類語 + アクター語彙 + シグナル語彙 + 現在の年月** で構成する。

- **A. 政治**: 大臣/首相/与党 + 表明/発言。担当大臣はテーマから管轄省庁を推論（防衛/経産/デジタル/金融/厚労/国交/文科/環境/農水）。現職氏名はハードコードせず検索結果から拾う。**閣議決定より早く株価に効く**
- **B. 行政**: 政府/省庁/閣議決定/審議会/検討会。狙いは行動計画・補正予算・規制改正
- **C. 海外**: 米国/中国/EU/関税/輸出規制。同業国の政策、対立構造、サプライチェーン影響
- **D. 企業**: 決算/業績修正/提携/受注。代表銘柄の個別材料

期間は **今日 → 直近1週間 → 直近1ヶ月** の順で、十分な材料が見つかれば打ち切り。

A〜D のいずれかで「介入」「数値コミット」「国際連動」シグナルにヒットしたら**最優先で採用**。

#### 4-3. 騰落率の符号に引きずられない

下落=悪材料、上昇=好材料という単純化はしない。**ランク変動と騰落率の組合せ**で資金フローを読む:

- 下落 × ランク↑ = 相対的資金逃避先（地合い悪化下の相対強さ）
- 上昇 × ランク↓ = テーマ内資金流出（他にもっと強いテーマあり）
- 下落 × ランク↓ = テーマ自体への興味後退
- 上昇 × ランク↑ = 明確な買い材料発生
- **NEW × 上昇** = 圏外からの突然のランクイン。新材料発生・ニュース起点を最優先で特定
- **NEW × 下落** = 騰落率は弱いがランクイン = 構造的注目シフト（先回り買い・思惑など）

ランク変動は騰落率より**資金フローを正確に映す**。NEW は前回ランキング外からの初登場で、特に注目すべき新興テーマ。

### 5. 推察

各テーマで以下を統合:

- 個別材料（手順4のA〜D）
- マクロ材料（手順3のM1〜M6）
- 過去履歴（手順1）の継続性・転換点
- 騰落率 × ランク変動の分類（4-3）

**全体相場との比較**:

- 市場リスクオン下の下落 = 個別逆風 or 高値警戒利食い
- 市場リスクオフ下の上昇 = **明確な相対強さ**
- 一極集中相場 → 蚊帳の外テーマは絶対値下落でもランクキープなら相対強さ

**材料の大きさとランク変動が釣り合うか**を自問。釣り合わなければ隠れ材料の可能性、追加検索する。推察は「〜と考えられる」「〜の可能性」で推測明示。

### 7. 履歴保存

`.claude/skills/theme-news/history/{今日}.md` に要約を Write。ディレクトリ無ければ `mkdir -p`、同日再実行は上書き、URL含めず1行圧縮。

```
# テーマ急上昇ニュース要約（{今日の日付}）

## 市場全体
- 地合い: {1行}
- 重要マクロ材料: {1-2行}

## 1. {テーマ名} ({騰落率}, {ランク変動: ↑N/↓N/→/NEW})
- 材料: {最重要材料1行・アクター種別含む}
- 推察: {結論1行・市場全体との相対位置に触れる}

## 2. ...
## 3. ...
```

## 注意事項

- 各テーマ2-3件の材料に絞る
- 出典URLを必ず付記
- HTML不在/テーマランクセクション無しは早期終了（保存スキップ、原因と再生成案内のみ伝える）
- 検索ヒットなしは「関連ニュースが見つかりませんでした」と記載し市場動向から推察
- 履歴読込失敗もエラーにせず新規調査として継続
