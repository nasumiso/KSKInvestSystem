# 資金管理の検証 2026-11

- **問い**: 2026-11-22 に改めた資金管理 (相場温度による張りたい量・口座の余裕による張れる量・週1段) は、それぞれ足す価値があるか。旧方式 (全域の逆張り) と比べてどうか
- **検証日**: 2026-11-26 (#594)
- **結論**: **口座の上限は採る。相場温度 (F&G・感情) で倍率を上下させる仕組みは、順張りも逆張りも外す。** 恐怖時の買い向かいは、F&G ではなく信用評価損益率の「−15% 以下で改善」を合図にする。ふだん 1.2倍、合図から3か月は 1.6倍、四半期末の高値の置き換えは残す。旧方式は全部の版の中で一番悪かった

## 前提

- 2025-01-06〜2026-11-25 の日々の保有を、約定と終値から復元した (`equity_history.py`。ETF を含む。楽天・SBI の残高 CSV と株数が一致することを確認)。**建玉1円あたりの日次リターン**に、ルールが決めた倍率を重ねて、元手1の資産の動きを出した (`money_rule_sim.py run`)
- **実際の保有に倍率を重ねたら、の評価で、銘柄の入れ替えは再現しない。** 倍率は週に1回 (金曜の引けで決めて翌営業日から)、週の中は建玉を固定。金利・手数料は入れない
- 相場温度の日本版 F&G は、その日までのデータで計算し直した。5成分がそろうのは 2025-10-28 から。それより前は3成分 (モメンタム・VI の乖離・安全資産) で、5成分との5区分の一致は **58%** だけなので、それより前の相場温度の結果は参考扱い
- 感情スコアは記録が 2026-10 以降しか無く、入れられなかった
- 保有の期間は約23か月で、今回の損失を見て作ったルールを同じ期間で測っている。そのため、保有での結果に加えて、**日経平均の長期** (2001〜、信用は 2009〜) でも確かめた (`money_rule_sim.py nikkei`)。日経平均は保有 (成長株中心) とは値動きが違うので、市場全体の傾向として読む

- 相場温度ごとのその後4週の保有のリターンは、3成分の期間では順位相関 +0.29、5成分の期間では −0.12 で、向きが入れ替わる。どの段も5〜21週しかなく、効くとも効かないとも言えない量
- **過熱で減らす (A4) は損だった。** +3 に入った9回のうち7回は、その後8週の保有のリターンがプラス
- **旧方式は全部の版の中で一番悪い。** 恐怖が続いた局面で倍率を上げ続け、暴落の期間だけで −48%。急落からすぐ戻った関税ショックでは一番良かったが、下げが何週も続く局面で傷が深くなった
- 張れる量の幅 (15%・25%)、上限を超えたら一気に戻す、+3 で直接移る は、差がわずかか効かなかった。日経VI の上限 (1週で 3σ 動いても追証に届かない倍率) は緩すぎて、一番低い週でも 2.66倍 (VI 44.6 の 2026-11-06 でも 2.77倍) と 1.2倍を一度も下回らず、上限なしと同じ結果だった。下方ボラの上限は上限に当たる週が倍になって最大ドローダウンは 1pt だけ下がった

読み取れること:

- **点数とその後の向きには関係がない。** 3か月後は帯によらず +1〜+4% でばらつく。関係があるのは荒れ方で、20未満では翌1か月の変動が大きくなる。その後の値動きで境目を決めるのは、ノイズに合わせることになる
- 時代による分布のずれはない (2年の分位で正規化しているため)。5成分は3成分より高い側が狭い (同じ日の 90%点は 5成分 73.0、3成分 85.9)。成分が多いほど平均が50に寄る
- 境目は、CNN と同じ頻度で各区分が出る値にした。CNN の累積割合 13.9 / 47.2 / 63.2 / 94.6% に当たる日本版の分位点は、5成分 (本番) で **24.8 / 51.5 / 56.7 / 77.1**、3成分の長期 (参考) で 20.5 / 52.0 / 61.3 / 80.5。新しい境目は **25 / 51 / 57 / 77** (判断は [2026-11-27 の判断記録](../../decisions/2026-11-27-日本版FGの5区分はCNNと同じ頻度になる閾値にする.md))
- ユーザーの使い方 (Extreme は感情に逆らう、それ以外は順張り) に照らすと、Extreme Fear のあとはふだんより悪くならないので、投げ売りしないことには筋が通る。積極的に買う根拠になるのは、VI 30超もそろうとき (§8) か 10未満のときに限られる。Extreme Greed のあとはややふだんより弱いが暴落の前触れではないので、高値を追って買い増さないことには使えても、売る根拠にはならない。中間の区分で量を順張りに増減する案は §7・§8 で上乗せが出なかったので、順張りは銘柄選びの側で効かせる

## 判断 (2026-11-26、ユーザー判断)

- **張る量 = ふだん 1.2倍と、口座の上限の小さい方。信用評価損益率が −15% 以下で改善したら、3か月だけ 1.6倍まで上げる (口座の上限が先に効く)。週1段で近づき、四半期末に高値を置き換える**
- **F&G と感情スコアは量の計算に使わない。** F&G は表示と日次ログに残し、Extreme Fear は「準備の合図」(拾う候補と余力を確かめる)、Extreme Greed は保有の点検 (#589) のきっかけにする。感情スコアは日曜の見直しで週1回記録し、行動のブレーキに使うかは #530 (行動との突き合わせ、12月末) を見て決める
- 過熱で減らす仕組みは持たない。過熱のあとの下げからは、口座の上限が守る (先読みせず、口座が高値から下がり始めてから減らす)
- 実装は #593
