# 買い圧力レシオの検証 2026-11

- **問い**: 買い圧力レシオ (`price.calc_sell_pressure_ratio`) は、モメンタム銘柄の上昇ピーク付近での利確・売り抜け検知として妥当か
- **検証日**: 2026-11-28
- **関連**: #617、[防衛ラインの検証 2026-11](防衛ラインの検証_2026-11.md)
- **結論**: **現行の買い圧力レシオ (40 / 45) は利確の目安として機能していない** (崩れを捉える時点ではすでに高値から -26%〜-56%)。同じ発想を終値位置 (CLV) ベースに変えた週足 CMF は市場全体では好成績だったが、**自分の実売買では現行の防衛線 (10WMA / 30WMA 割れ確定) に速度・誤爆率とも及ばなかった**。買い圧力レシオは利確判断から外し、#617 の TMF 検証でも「自分の実売買で防衛線に上乗せ価値があるか」を基準にする

## 1. 数式上の性質 (`scripts/price.py`)

4区間の値幅から買い/売り出来高を按分しているが、代数的に展開すると常に `buy - sel = C - prev_C` となり、当日の買い比率は `0.5 + (C - prev_C) / (2 × 経路長)` に帰着する。

- **寄り天・大陰線の見逃し**: 前日比プラスなら必ず 50%超になる。日足 2,053銘柄 (約62営業日) のギャップアップ寄り天大陰線 (`C > prev_C` かつ終値 <= 始値 -3%) 288件は **100.0% が買い優勢 (>50%、中央値 54.0%)** 扱いだった
- **エコー効果**: 19日間の出来高単純合算のため、大出来高の日が窓から落ちただけで急変する。`spr20` が1日で -10pt 以上急落した 424件のうち **24.1% (102件) は当日値動き ±1% 以内**
- **遅行性**: 過去19期リターンとの相関は日足 `r = 0.535`・週足 `r = 0.546`

## 2. 市場全体での検証 (開発用キャッシュ)

本格モメンタム局面 (26週内 +50%超・高値比 -25%以内、1,992銘柄・週足2年) の前後半比較:

|---|---|---|
| ベースライン (継続保有) | 1,103 / 0.0% / +5.7% / 43.1% | 1,044 / 0.0% / +7.2% / 41.6% |
| `sprw20 <= 45` | 34 / -20.8% / -3.1% / 52.9% | 27 / -18.4% / -0.1% / 51.9% |
| `buygather <= 45` (出来高平均超) | 84 / -14.7% / +2.1% / 46.4% | 68 / -17.7% / +1.0% / 45.6% |
| `wma10割れ & sprw20 <= 45` | 17 / -18.7% / -10.0% / 58.8% | 15 / -18.4% / -3.1% / 53.3% |
| 比較: 週足 `CMF20 <= -0.10` | 336 / -10.0% / -10.1% / 61.6% | 213 / -12.5% / -9.2% / 62.9% |

- `<= 40` は極めて稀 (週足2年全体で N=10・高値比 -21.7%、日足62日でも N=17・高値比 -12.9%)
- 日足 `spr20 <= 45` (上昇 +20%超銘柄、N=125) は高値比 -10.9% で出た後の 20日先中央値が **+2.3%** (ベースライン +0.9% より反発) となり、天井ではなく押し目の底で反応していた

## 3. 自分の実売買エピソードでの検証 (運用機正本)

全 461 エピソードのうち、買い・分割疑い除外・保有4週以上・週足範囲内の **144件** を対象に、ピーク含み益 +20% 超の **A群 (ピークから -20%以上崩れ: 20件)** と **B群 (-15%以内で維持・利確: 40件)** で比較 (MA割れは `exit_line.calc_ma_violation` と同一の確定判定)。

| 週足シグナル | A群 (崩れ20件) 捕捉 / 高値比 / ピーク差 / 改善・悪化 | B群 (勝ち40件) 早売り誤爆 / 対実績差 |
|---|---|---|
| `spr_w <= 40` | 5 (25%) / -56.0% / +18.0週 / 3勝1負 | 0 (0%) / — |
| `spr_w <= 45` | 11 (55%) / -45.1% / +10.0週 / 6勝5負 | 1 (2%) / -39.4% |
| `buyg_w <= 45` | 14 (70%) / -31.6% / +6.0週 / 11勝1負 | 4 (10%) / -20.1% |
| `cmf_w <= -0.10` | 15 (75%) / -39.2% / +4.0週 / 9勝6負 | **12 (30%) / -20.7%** |
| **`wma10_viol` (≒50DMA)** | **19 (95%) / -25.9% / +3.0週 / 17勝1負** | 15 (38%) / -19.1% |
| **`wma30_viol` (30WMA)** | **16 (80%) / -33.7% / +4.5週 / 10勝5負** | **4 (10%) / -29.0%** |

- **崩れ代表例**: 4970 東洋合成 (+162%→0%) は `wma10_viol` が +2週 (高値-15%)、`wma30_viol` が +7週 (-34%) に対し `spr_w <= 45` は +10週 (-44%)。6134 FUJI・6890 フェローテック・4461 第一工業製薬・9337 トリドリでも `spr_w <= 45` は高値 -47〜-53% の底値圏で点灯
- **勝ち株の誤爆**: `wma30_viol` は 7685 バイセル (+150%)・6920 レーザーテック (+101%)・6232 ACSL (+99%)・3697 SHIFT (+75%)・6315 TOWA (+75%) を全件持ち切ったが、`cmf_w <= -0.10` はバイセル (-50%)・ACSL (-31%)・TOWA (-20%) で途中誤爆
- **日足 (2026年秋暴落・直近60営業日で高値比 -15%以下の1保 17件)**: `ma10_viol` がピーク後 +5営業日 (高値比 -10.8%) で全件捕捉したのに対し、`spr20 <= 45` は +10営業日 (-25.8%)、`cmf20 <= -0.10` は +10営業日 (-29.6%)、`spr20 <= 40` は +15営業日 (-33.7%) と大きく遅れた

## 4. 判断と #617 への引き継ぎ

- **現行の買い圧力レシオは利確の判断軸に使わない**。特に日足 `<= 45` は押し目での早売りリスクが高く、崩れ局面では遅すぎる
- **大崩れした実売買の大半は、すでに防衛線 (`wma10_viol` / `wma30_viol`・早売 `ma10_viol`) が先に鳴っていた**。新しい出来高オシレーターで利確を当てにいくより、既存の防衛線を守る方がシンプルで成績が良い
- **#617 (TMF 検証) で確認すべき基準**: 市場全体テストでは CMF のような CLV 系が良く見えても、自分の勝ち株での早売り誤爆で帳消しになりうる。TMF を入れるかは「①自分の実売買 (特に勝ち株での誤爆率) でも通るか」「②既存の防衛線 (50MA / 30WMA / 早売10MA) に比べて先行性・上乗せ価値があるか」で判断し、無ければ簡素化・廃止も選択肢に入れる
