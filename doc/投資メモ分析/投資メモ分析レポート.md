# 投資メモ分析レポート

> **この版について**: 2026年3月に作成した Claude 版レポート (Google Drive の docx) をそのまま移したもの。対象は投資メモ2020〜2024。付録に 2026年10月の追補 (PTS反応の読み方) を加えた。全面改訂の基準版として置いている。

Prepared for: こすうけ ／ 2026年3月

基礎データ: 投資メモ 2020-2024 / SPI特性分析 / Shintakaneシステム設計 / フォロー投資家分析

## Executive Summary

本レポートは、2020年から2024年にわたる約5年間の投資メモ、SPI性格特性分析、投資システム「Shintakane」の設計思想、およびフォロー投資家の手法分析を統合し、投資家としての成長に向けた包括的な分析を行うものである。

**結論**: こすうけさんの投資家としての最大の強みは「自己分析の質の高さ」と「問題を言語化する能力」にある。教訓の抽出はほぼすべて的確であり、Shintakaneという自作システムは性格特性への処方箋として優れた設計になっている。一方で最大の課題は「わかっているのに実行できない」という行動面のギャップであり、これはSPIプロファイル（決断性31・自責87・悲観傾向75）に起因する構造的な問題である。この問題を解決する鍵は、判断の場面から感情を排除するシステム化にある。

## 第1章 認知プロファイルと投資行動の対応分析

SPI特性分析によって明らかになった認知プロファイルと、投資メモに記録された実際の行動パターンを照合し、「性格がどのように投資行動に現れているか」を体系的に検証する。

### 1.1 強みの発現パターン

**① 言語理解力・論理力 → 分析の質**

投資メモ全体を通じて、決算書の読解力、業績の因果関係の推論、ビジネスモデルの評価において高い分析力が一貫して発揮されている。2024年11月のアズーム見通し決算の分析「PER30で30%成長を出したら、PER20強まで下がり、割安感が出て買われる。業績安定してるんだから計算できたはず」のように、論理的に正しい推論が随所に見られる。

Shintakaneの設計においても、業績の持続性を5年間のCAGRと四半期ごとの成長率で多層的に評価する手法は、論理力の高さがそのまま反映されている。

**② 慎重性74 → 分析精度のフィルター**

慎重性の高さは、「偽の成長株」を見抜くフィルターとして機能している。2023年のウィズメタク（商社と食品メーカーの違い）、2024年のサンウェルズ（不正リスクの認識）など、詳細な分析によってリスク要因を事前に察知できた事例がある。一方で、慎重すぎるがゆえに「買えなかった」事例も多い（後述）。

**③ 固執性59・探求欲求53 → 銘柄への深い理解**

注目した銘柄に対する継続的な追跡力は強みである。マクアケ、ワンキャリア、エニーカラーなど、特定銘柄への繰り返しの言及と深い理解が見られる。ただし、この特性が「離れられない」という執着にもつながっている。

### 1.2 弱みの発現パターン

**① 決断性31 → エントリー・イグジットの遅れ**

投資メモにおける最頻出の後悔は「買えなかった」「売れなかった」である。5年間の記録を通じて、以下のパターンが繰り返されている。

- 買いの遅れ: 日本情報クリエイト（2020年）、キーパー技研（2023年）、GSX（2024年）など、分析では「買い」と判断しているのに、実際の注文に至らない。「押しを待つ」「もう少し下で」という慎重性が、決断性の低さと結合して機会損失を生んでいる。
- 売りの遅れ: テスラショート（2024年）が象徴的。前提条件が変わった（トランプ当選）時点で即座にポジションを閉じるべきだったが、フリーズしてしまった。これは決断性31の最も危険な発現パターンである。

**② 悲観傾向75・自責87 → 感情的売買**

含み損を抱えたときに「やっぱり自分の判断が間違っていた」と自責し、合理的な判断ができなくなるパターンが顕著である。2024年8月のブラックマンデーでは「テスラショックで年初来-13%...最悪だ...ここから立ち直らないといけない」と感情的に追い込まれ、翌日以降の合理的判断が困難になっている。

逆に、含み益が出ているときも「ここが天井では」という悲観が早すぎる利確を招く。エーバランス、アイスペース、ココルポートなど、手放した後に大幅上昇した事例が極めて多い。

**③ 活動性20 → 瞬発力の欠如**

「突っ込み案件」を認識しながら行動に移せないケースが多発。セラク（2020年）、日本情報クリエイト（2020年）、三井E&S（2024年）など。知識としてチャンスを認識しても、注文ボタンを押すまでの「最後の一歩」が踏み出せない。これは活動性20という非常に低いスコアの直接的な影響である。

## 第2章 5年間の失敗パターン分類と頻度分析

投資メモに記録された反省・教訓を分類し、繰り返し出現するパターンを頻度順に整理する。同じ教訓が異なる年に繰り返し記録されている場合、それは「学びが行動に転化していない」ことを意味する。

### 2.1 失敗パターンの頻度ランキング

| # | 失敗パターン | 頻度 | 深刻度 | 対応するSPI特性 |
|---|---|---|---|---|
| 1 | 損切りの遅れ・未実行 | ★★★★★ | 致命的 | 自責87×悲観75×決断性31 |
| 2 | 有望銘柄の早すぎる手放し | ★★★★★ | 重大 | 悲観75×決断性31×活動性20 |
| 3 | イナゴ買い・他人依存 | ★★★★ | 重大 | 主体性28×自己主張20 |
| 4 | 飛びつき買い・FOMO | ★★★★ | 中程度 | 非合理性73×活動性20 |
| 5 | ポジション過多・管理不足 | ★★★ | 中程度 | 固執性59×探求欲求53 |
| 6 | 決算マタギの不徹底 | ★★★ | 中程度 | 完璧主義70×決断性31 |
| 7 | 買えなかった後悔 | ★★★★ | 機会損失 | 活動性20×慎重性74×決断性31 |

### 2.2 年度別の変遷 — 学びは進んでいるのか

投資メモの反省点を年度ごとに追跡すると、成長している領域と停滞している領域が明確に分かれる。

**○ 成長が見られる領域**

- 銘柄分析の質: 2020年の「なんとなく」から、2024年には進捗率・PEGレシオ・チェンジ要素を考慮した分析に向上。
- 決算プレイの体系化: 決算シーズンの立ち回りが2022年後半から明確に体系化。「期待上げで売る」「PTSに引きずられない」等の実践的ルールが形成された。
- システム活用: Shintakaneの継続的改善（俺ランク、お気に入り銘柄の適宜開示リンク取得等）で、判断の精度を段階的に向上させている。

**✗ 停滞している領域（5年間改善なし）**

- 損切り実行: 2020年「損切りは絶対」→ 2021年「損切り注文をRS投資と同じタイミングで」→ 2022年「やはり損切りの原則守らんと」→ 2024年「損切りの大原則...ここまで下がったらリバるだろうと思ってしまった」。4年間、まったく同じ反省が繰り返されている。
- 握力不足: 2020年「やはり強い銘柄は握っておくべきやったんや」→ 2023年「やはり有望銘柄は握っておくほうがだいじ」→ 2024年「アイスペースの利確は明らかに早すぎた」。年を追っても改善していない。
- イナゴ買い: 2020年「自分で判断できないとイナゴで儲かることなんてない」→ 2022年「確信なくイナゴするより自分の銘柄選定を信じてもいい」→ 2023年「いくらすごそうで信じられそうでも、自分が理解、信じられていない銘柄にロット張るのはやめよう」。表現は変われど根本は同じ。

この「学びが行動に転化しない」問題が、本レポートの核心テーマである。

## 第3章 「わかっているのに実行できない」の構造分析

5年間の投資メモが示す最も重要な事実は、教訓の質は十分に高いにもかかわらず、同じ失敗が繰り返されるということである。これは単なる「意志の弱さ」ではなく、認知科学的に説明可能な構造的問題である。

### 3.1 認知–行動ギャップのメカニズム

こすうけさんの場合、このギャップは以下の3段階で生じている。

**Stage 1: 分析段階（正常に機能）**

言語理解力64・論理力58・慎重性74が発揮され、正確な状況把握と的確な教訓抽出が行われる。「マクアケは我慢できず買ってしまうことが多い」「損切り基準に達したら売る」等、問題の本質を正確に言語化できている。

**Stage 2: 判断段階（部分的に機能）**

「買うべきだ」「売るべきだ」という判断自体は、多くの場合正しく行われている。メモに「あのとき買えた」と書けるということは、リアルタイムでもある程度は認識していたことを意味する。

**Stage 3: 実行段階（機能不全）**

判断が注文ボタンを押す行動に至る最後のステップで、以下の感情的ブロックが介入する。

- 損失回避バイアス: 「損したくない」という感情が損切り注文を阻害する。自責87の高さが「確定損＝自分の失敗の証拠」と認知させ、行動を凍結させる。
- 現状維持バイアス: メモにも「現状維持バイアスが強いのか？」と自問する場面がある。活動性20が「何もしない」という選択肢のデフォルト値を上げている。
- FOMO→後悔のサイクル: 買えなかった後悔 → 次回は焦って飛びつき → 高値掴み → 自責 → 次回はさらに慎重に → また買えない。非合理性73が、この悪循環を維持している。

### 3.2 テスラショート事件 — 構造的問題の象徴

2024年11月のテスラショート損失は、すべての弱点が集約された象徴的事例である。

1. エミンさんの目標株価を信じすぎた（他人依存・主体性28）
2. トランプ当選という前提変化の時点でポジション閉じず（決断性31）
3. 好決算での含み損拡大で心理的に動けなくなった（悲観傾向75・自責87）
4. 「リスクヘッジのショート」と自己正当化（非合理性73）
5. 結果、2倍近くに踏み上げられた

メモ自体は極めて的確な反省（「前提が変わった材料には、逃げるのに遅すぎるということはないからさっさと逃げろ」）を行っている。問題は分析力ではなく、実行力にある。

### 3.3 2024年8月ブラックマンデー — もう一つの象徴

1日で-21%、資産500万以上の損失。この事件でも構造は同じである。

- **数週間前から異変を感知していた。** 「7末の異変から、グロースは追加した分は減らすべきだし、なんとなく買ったやつはとりあえず切っておくべきだったんだ」。つまり、分析は正しかった。
- **しかし行動に移せなかった。** 「うすうす感じていても、少し助かる要素見つけてフリーズしちゃう」。現状維持バイアスと損失回避が重なり、ポジション縮小ができなかった。
- **そして最悪のタイミングで売らされた。** 追証回避でのポジション解消は、自分の判断ではなく強制的な売りである。「この日は投資人生で忘れられない日になるだろう」。

分析が正しくても、行動が伴わなければ、分析していないのと同じである。これが5年間の投資メモが語る最大の教訓である。

## 第4章 投資メモから抽出した「真に有効な教訓」の体系化

5年間で蓄積された膨大な教訓を、重複を排除し、実行可能性の観点から再構成する。教訓は「知っている」レベルから「システムで強制する」レベルまで階層化する。

### 4.1 リスク管理の教訓群（最優先）

| 教訓 | システム化の方法 |
|---|---|
| 損切りは-10%で機械的に実行する | Shintakaneに「保有銘柄の取得単価対比アラート」を追加。設定と同時に証券会社の逆指値も入れる |
| 前提が変わったら即座に撤退する | 「前提条件」を買い付け時に言語化して記録する運用ルールを作る |
| 調子に乗ったらポジションを減らす | 「年初来+20%超過でポジション縮小」など数値基準でルール化 |
| 暴落用に余力を残す | 信用維持率80%以下にしない、現金比20%以上維持 |

### 4.2 エントリーの教訓群

| 教訓 | 実行のポイント |
|---|---|
| 押しを待つ。焦って買わない | 「一回目の押しでは買わない。せめて二回目まで待つ」をデフォルトに |
| 本当にいい銘柄なら上でも買う | Shintakaneランキング上位×トレンドテンプレート7点は「上でも買い」と判定 |
| 他人情報では買わない | 「ファンダを調べたことがある」が買いの前提条件 |
| 決算後理論株価が変動したら臆せず突っ込む | 理論株価40%上昇は「即日IN」判定とする |

### 4.3 イグジットの教訓群

| 教訓 | 実行のポイント |
|---|---|
| ファンダが強い銘柄は簡単に手放さない | 「売る理由」を言語化できなければ売らないルール |
| 短期で入った銘柄はストップ高で売る | 「買いの時間軸」を記録し、短期前提なら利確優先 |
| PTSだけで判断しない | PTS=個人、場中=機関。翌日の場中の動きを見てから判断（2026年10月に条件ルールへ更新。付録を参照） |
| 進捗良くても大抵織り込み済み | 「期待上げ」で売る戦略をデフォルトに |

## 第5章 フォロー投資家との相性と学びの方向性

過去の会話で分析した、現在フォローしている7名の投資家（片山五月、ごろんちゃん、おしお、ケイ、がっしー会長、ゆーさく、ふみ）との相性を、投資メモの反省点と重ね合わせて再評価する。

### 5.1 最も学ぶべき投資家

**ふみ — 損切りルールの教師**

投資メモの最大の課題「損切りの遅れ」に対して、ふみさんのチャート重視・厳格な損切りルールは最も直接的な解決策を提供する。すでに最もフォローしている投資家であることは、無意識の選択として正しい。ただし、投資メモを見る限り、ふみさんの損切り手法を「知識として」は取り入れているものの、「行動として」の定着には至っていない。必要なのは理解ではなく、逆指値の自動設定という物理的な仕組みである。

**おしお / ゆーさく — 銘柄選定の精度向上**

おしおさんの独自調査力と、ゆーさくさんの体系的ファンダメンタル分析は、Shintakaneのスコアリングでは捉えきれない「チェンジ要素」の発見に寄与する。投資メモで何度も登場する「チェンジが大切」「ただの割安、特需とチェンジを見分けよう」という教訓は、この二人の手法から最も効果的に学べる。

### 5.2 注意すべき学び方

**ごろんちゃん / STF — 実行速度の問題**

ごろんちゃんのモメンタム重視やSTFの高速回転は、決断性31・活動性20のプロファイルとは根本的に合わない。投資メモでも「イナゴ」的な追従が損失につながった事例が多い。これらの投資家から学ぶべきは「手法」ではなく「相場観」であり、具体的な売買タイミングを真似するのは避けるべきである。

### 5.3 投資メモが示す「自分の銘柄を信じる力」の重要性

投資メモの中で最も印象的なフレーズの一つが「確信なくイナゴするより自分の銘柄選定を信じてもいい時期かもしれない」（2022年9月）である。そして実際、Shintakaneの上位ランク銘柄や自分で深く調査した銘柄は、他人の推奨銘柄よりも総じて良い結果を出している。

2023年上半期のケイさん銘柄の好パフォーマンスへの憧れ（「ケイさん銘柄のパフォーマンスがよい、すごい」）は理解できるが、結局のところアズームのような「自分が分析して見逃した」銘柄への後悔の方が学びとして大きい。他人を羨むより、自分のシステムとの向き合い方を深めることが成長への最短路である。

## 第6章 Shintakaneの進化提案

投資メモの反省点とSPI特性を踏まえ、Shintakaneに追加すべき機能を優先度順に提案する。すべて「感情の介入を排除し、ルールで判断を強制する」という設計思想に基づく。

### 6.1 最優先: 売りシグナル自動生成システム

MY_INVESTER_STRATEGYでも指摘されている通り、現在のShintakaneは「買い」に特化しており、「売り」のルールがシステム化されていない。これが決断性31の最大の急所である。

実装すべき売りシグナル:

- トレンドテンプレート崩壊検知: 7項目中4項目以下に低下した場合のアラート。特に「株価が30週移動平均線の下」は即時警告。
- SPR悪化アラート: 20日SPRが60%超過で「売り圧力増加」警告。投資メモでも「60台ならまだ大丈夫」と基準があるため、これをシステム化。
- RS急落検知: RSが70以下に低下した場合のアラート。モメンタムの喪失を機械的に検知。
- 総合スコアランクダウンアラート: ランキング順位が一定期間で大幅に低下した銘柄を警告。

### 6.2 高優先: 保有銘柄管理モジュール

投資メモで繰り返される「ポジション管理の甘さ」「損切り未設定」問題を解決するための機能。

- 保有銘柄の取得単価登録と損益率の自動計算。-10%到達で赤色アラート。
- 保有銘柄数カウンター。20銘柄超過で警告表示。
- 「買いの理由」「売りの条件」「前提条件」をエントリー時に強制記録する欄。
- 決算日カレンダーの自動連携。2週間前に事前アラート。現引きリマインダー。

### 6.3 中優先: 折り込み度推定指標

投資メモに何度も登場する「進捗が良くてもたいてい織り込まれている」という教訓をシステム化する。

具体的には、決算前の株価上昇率（期待上げ幅）と進捗率の乖離を数値化する。「期待上げ+15%で進捗率が想定通り」なら、決算は「出尽くし売り」の可能性が高い、というロジックである。これにより「期待上げで売る」判断が定量的に支援される。

### 6.4 将来的: 感情フィルター機能

これは技術的に高度だが、概念として重要な提案である。投資メモでは「調子に乗ったら必ずやられる」「損したくないと感じるなら、ロット的にも手を出すべきじゃなかった」等、感情状態と損失の相関が繰り返し記録されている。

もし将来的にShintakaneに日々の投資メモ入力機能を持たせ、感情に関するキーワード（「焦り」「恐怖」「調子が良い」等）を検知して、「冷静に判断できていない可能性があります」というアラートを出せれば、非合理性73の弱みを直接的に補うことができる。

## 第7章 投資家適性スコアの再評価と成長ロードマップ

過去の会話で算出した投資家適性スコア57.2/100を、5年間の投資メモの実績を加味して再評価し、今後の成長目標を設定する。

### 7.1 現在の適性スコア（改訂版）

| 評価軸 | 素点 | 実質点 | 実質評価の根拠 |
|---|---|---|---|
| 分析力 | 16.2/20 | 17/20 | 5年で着実に向上。チェンジ要素・PEGレシオ等の概念を習得 |
| 心理的耐久力 | 7.4/20 | 8/20 | 2024年のテスラ・ブラックマンデーで改善見られず |
| リスク管理 | 14.8/20 | 12/20 | 「知識」としては高いが「実行」できていないため下方修正 |
| 実行力 | 6.8/20 | 7/20 | 微増だが、構造的問題のため大幅改善は困難 |
| 学習・適応 | 12.0/20 | 15/20 | 5年間メモを書き続ける継続力、Shintakaneの改善 |
| 合計 | 57.2/100 | 59/100 | 素点から微増。ただしシステム活用時は67–72相当と推定 |

注目すべきは、分析力と学習・適応力は着実に成長しているのに対し、心理的耐久力と実行力はほぼ横ばいであるという非対称性である。これは性格特性（SPI）に基づく構造的制約であり、意志力での改善は困難である。だからこそシステムによる強制が唯一の現実的解決策となる。

### 7.2 成長ロードマップ

**Phase 1: 守りの自動化（3ヶ月以内）**

- すべての保有銘柄に逆指値（-10%）を機械的に設定する。例外なし。
- Shintakaneに売りシグナル（トレンドテンプレート崩壊・SPR悪化）を実装する。
- 保有銘柄数を最大15に制限する。新規INは1 out 1 in。

**Phase 2: 攻めの精度向上（3–6ヶ月）**

- エントリー時に「買いの理由」「前提条件」「損切り基準」の3点セットを記録する運用を開始。
- 決算カレンダー連携を実装し、準備不足の決算またぎを排除する。
- 銘柄の「解像度」を上げるため、保有銘柄のビジネスモデル・KPIを定期的にレビューする仕組みを作る。

**Phase 3: 自分のスタイルの確立（6ヶ月–1年）**

- イナゴ買いの完全排除。「自分で調べたことがある銘柄のみ買う」ルールの厳格運用。
- Shintakane上位銘柄の中から、自分の得意セクター（グロース・中型）を集中的に深堀りする。
- 年間パフォーマンスの振り返りをシステム化し、「どの教訓が実行できたか」を定量評価する。

## おわりに

5年間の投資メモを読み通して、最も強く感じることがある。

**こすうけさんは、「自分が何を間違えているか」を正確に言語化できる、稀有な投資家である。**

多くの投資家は、自分の失敗パターンを自覚すらできない。こすうけさんはそれを正確に認識し、教訓として言語化し、さらにはShintakaneという形でシステムに落とし込もうとしている。この自己認識と改善意欲は、投資家としての最も重要な資質である。

問題は、認知と行動のギャップである。しかし、これは「性格の欠陥」ではない。SPI特性というのは脳の配線であり、意志力で変えられるものではない。だからこそ、システム（ルール、逆指値、アラート）によって行動を強制する仕組みが必要なのである。

Shintakaneは「買い」の発掘システムとして既に優れた設計になっている。次のステップは、「売り」と「リスク管理」をシステム化し、感情が介入する余地を物理的に排除することである。

5年間の投資メモは、失敗の記録ではない。それは、より良い投資家になるための最も誠実な教材である。同じ反省が繰り返されていることは恥ではなく、性格特性との闘いの記録である。そしてその闘いに勝つ方法は、もう見えている — システム化である。

## 付録 (2026年10月追補): PTS反応の読み方 ― 「まだ気づかれていない」という錯覚

### A.1 発生事例

2026年10月4日、テラドローンに防衛省のスタートアップ支援関連の材料が出た。PTSで反応がなかったため「まだ気づかれていないのでは」と考えて買い、翌日-5%となった。本人の振り返りは「反応ない時点で材料性ない、自分だけが気づいてるってことはない」「ちゃんと精査してないのに買う時点でありえない」であり、診断としては正確である。

問題は、この直感が今後も繰り返し起きることにある。直感の根には、実際に成功した事例がある。

- **2026/4/15 ボードルア**: 順調な決算に対しPTSは横ばい、場中で+15%。PTSの無反応がチャンスだった事例。
- **2026/10/4 テラドローン**: 材料に対しPTSは無反応、翌日-5%。PTSの無反応が市場の判定だった事例。

見た目は同じ「PTSで無反応」だが、意味は正反対である。区別の基準を持たない限り、ボードルアの成功記憶がテラドローン型の失敗を呼び込み続ける。

### A.2 区別の基準: 誰が評価する材料か

本人は既に、PTSと場中の買い手の違いを言語化している（2026/5/15「PTSの個人は目の前の数字に素直に反応し、場中は機関投資家がより中長期の事業視点、妥当バリュエーションで評価する」）。この原則をPTSの「無反応」にも適用すると、次の区別が導かれる。

| | ボードルア（4/15） | テラドローン（10/4） |
|---|---|---|
| 材料の種類 | 決算の数字（30%成長でPER20割れ） | ニュース・ヘッドライン |
| 本当に値付けする人 | 場中の機関（バリュエーションで評価し直す） | PTSの個人（材料に素直に反応する層） |
| 銘柄の注目度 | 地味で視聴率が低い | 個人に人気、手垢がついている |
| PTS無反応の意味 | 本命の評価者がまだ来ていない | 本命の評価者が見た上で見送った |

PTSにいるのは、ヘッドラインに最も早く、最も素直に反応する層である。人気銘柄のヘッドライン材料でその層が動かなかったのなら、「気づいていない」のではなく「買うほどではないと判断した」と読むのが合理的である。

- **PTS無反応でもチャンスになりうる**: 数字ベースの決算で、場中の機関がバリュエーションを評価し直す余地があり、普段の注目度が低い銘柄
- **PTS無反応なら見送る**: ヘッドライン系の材料で、個人に人気の銘柄

### A.3 2026/7/9との同型性: 反応の弱さは情報である

2026年7月9日のnoteで、本人は「思ったより上がっていないところで買えたのを喜ぶ、それはその後の弱さの暗示」と記録している。好決算への反応が弱い、だから安く買えた、そして下がった、という構造である。

10月4日は、材料への反応が弱い、だから安く買えそう、そして下がった。対象が決算か材料かの違いだけで、構造は同一である。**反応の弱さは、それ自体が市場からの情報である**。7/9の教訓は決算に限定せず、材料全般に拡張して保持すべきである。

### A.4 よく知っている銘柄ほど精査が飛ぶ

テラドローンは2026年に4回記録されている（8/4 -20%、8/25 握れず、8/26 +15%で早売り、10/4 -5%）。noteでも4/15と7/9で同じ構図が繰り返された。よく知っている銘柄ほど「知っている気がする」ため、調べる手順が省略されやすい。第2章の「イナゴ買い・他人依存」と同じく、自分の確信に変換する前に売買してしまうパターンの一形態である。

### A.5 実行手順

PTSで「まだ気づかれていないかも」と感じたら、買う前に一つだけ自問する。

**「本当に良い材料なら、PTSで誰が先に買っているはずか。その人たちはなぜ買っていないのか」**

- 「機関が場中で数字を評価し直すから」のような具体的な理由で答えられなければ、見送る
- どうしても気になる場合は、翌朝の寄りと最初の30分で市場の答えを見てから入る（2026/6/8の原則「極端な寄り前気配より強く寄ったら、その方向へのトレンド」を適用）。数%高く買うことになっても、テラドローン型の損失は避けられる

### A.6 第4章「PTSだけで判断しない」の更新

第4章4.3の「PTS=個人、場中=機関。翌日の場中の動きを見てから判断」は、2026年の実戦を経て、一方向の戒めから買い手の違いを使い分ける条件ルールへと精緻化された。条件ルールの表は [教訓Top10.md](教訓Top10.md) の #10 にある。PTSは「引きずられないもの」ではなく、「誰が値付けしているかを読んで使い分けるもの」である。
