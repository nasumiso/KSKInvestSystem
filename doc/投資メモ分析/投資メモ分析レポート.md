## Executive Summary

**結論**: こすうけさんは、勝ち方をすでに見つけている。2025年1月〜2026年9月の21ヶ月で資金はおよそ2倍になり、TOPIX (+54%) とグロース (+25%) を大きく上回った。その実現益の78%は、91日以上持った44件から来ている。テーマの本流でリーダーを持ち切ることが、こすうけさんのエッジである。

一方で、同じ期間の0〜3日で決済した107件はトータルでマイナスで、2026年は91日未満のすべての保有期間帯で赤字になった。戦略宣言をせずに入った衝動・SNS発の取引 (2026年7月以降の20件) は、勝率30%・-115万円。**成績を削っているのは、もはや損切りの遅れではなく、エッジの外で行う短期の衝動売買である**。

もう一つの発見は、教訓が年をまたいで**ほぼ同じ文言で**再発見されていることである。「ポジションを減らすなら弱い銘柄から」は2020年7月・2024年9月・2026年6月の3回、「玉を分けて一部だけ長く持つ」は2023年4月から2026年10月までに4回書かれている。学ぶ力は十分にある。欠けているのは、発注の瞬間にその学びが目の前に出てくる仕組みである。

## 第2章 何が成績を生んでいるか

データとメモを突き合わせると、こすうけさんのエッジは3つに絞れる。

**① テーマの本流で、リーダーを、長く持つ。** 実現益の大半はこれで、2025〜2026年の半導体 (レーザーテック・キオクシア)、東洋合成の部分利確などが該当する。メモにも何度も書かれている: 「本当のトレンド、波は周辺のイベントでは衰えない」(2026/1/28)、「テーマが大きいほど本命銘柄に素直に乗るのがいい」(2023年の振り返り、NVIDIA)。

**② 自分で深掘りし、確信を持った銘柄。** 「週末にChatGPTと深堀して調べた銘柄が当たってる…これまで根拠をもって売買できなかったことができるようになった」(2025/2/17)。2024年3月に生成AIを銘柄調査に使い始め、2026年には評価台帳とMCPで一次資料ベースの評価が日常化した。分析レイヤーの強化は成績の改善と時期が重なっている。

**③ 仕組みで決める部分。** RS投資 (ETFのローテーション) は年次振り返りで毎年「間違いない」と評価されている (2021年インドNifty、2025年純金・エマージング)。裁量が入らない部分ほど安定して勝っている。

逆に、エッジの外にあるのは、場中の値動きやSNS・PTSをきっかけにした数日単位の売買である。こちらは2025年は小さくプラス、2026年は明確にマイナスで、時間と注意力を取られている割に成績に寄与していない。

これは「学べていない」のではない。毎回、正しい結論に**自力で**たどり着いている。問題は、数年前に自分が書いた結論が、同じ場面に立ったときに参照されないことである。

### 3.2 なぜ繰り返すのか

[投資戦略.md](../投資戦略.md) の認知プロファイル (決断性31・自責87・悲観傾向75・活動性20) は、この構造をよく説明する。分析と振り返り (言語理解・論理・慎重性) は機能していて、崩れるのは場中の数分で判断する場面だけである。16Personalities のレジリエンス17%は、2024年8月や11月のような大きな損失の後に判断が乱れ、「取り返そうと思う気持ち」(2024/4/22) から次の衝動売買が生まれる流れとも一致する。

2026年の記録からは、繰り返しに3つの型があることがわかる。対策も型ごとに違う。

| 型 | 例 | 効く対策 |
|---|---|---|
| **規律型**: やってはいけないと知っていてやる | 決算前じり下げの値ごろ買い、衝動・SNS発の短期売買 | 禁止ルールと関所。2026年6月の決算またぎ禁止以降、決算前の値ごろ買いは記録されていない |
| **情報型**: ストレス下で判断材料が手元にない | 急落時に強い銘柄を売る (2026/6/10) | 事前に並べた情報。RS順に並べれば、下から切ればよい |
| **準備不足型**: 事前に想定していない | 決算の見逃し (2026/7/9)、材料の大きさを測れない (フジクラ 2026/6/21) | 事前予告。決算カレンダー、イベント前に決めておく行動 |

## 第4章 改善したこと・していないこと

第1版は「損切り・握力・イナゴ買いは5年間改善なし」としたが、2025年以降のデータでは評価が変わる。

**改善した**

- **持ち切る力**: 91日以上の保有で +656万円。2026年も網屋155日・ボードルア127日・東洋合成などで +280万円。第1版で「停滞」とした握力は、テーマ本流の銘柄では機能するようになった
- **損失の大きさ**: 平均の負けは-5.5万円、ペイオフ1.81。2020〜2024年のホープ-90%・マクアケ-50%・オープンワークのような「持ち続けて致命傷」になる型は、2025年以降は平均値で見る限り抑えられている
- **決算またぎ**: 2026年6月にルール化して以降、決算前の値ごろ買いの記録はない
- **調査の質**: AIと評価台帳で、一次資料ベースの調査が日常になった

**改善していない**

- **回転過多と衝動売買**: 新規建ては2026年7月11件・8月22件で、前半 (月平均約23件) からほぼ減っていない。0〜3日の決済は2026年だけで44件・-55万円。宣言なしの取引は統制の外で、しかも赤字
- **保有銘柄数**: 28銘柄。目安 (実保有10＋打診5) の約2倍で、2020年から一貫して「絞る」と書き続けている (2020/8/28「せいぜい10銘柄」、2023/4/18「20前後」、2024/11/14「最大20」)
- **ボラの大きい材料株でのサイズ**: テラドローン (2026/8/4、2日で-20%)、トリドリ (-31万円) のように、損失の裾は残っている。逆指値の発注と、ボラに合わせたロットは手動のまま
- **発注ミス**: 2021年から2026年まで、売り買いや桁の取り違えが少なくとも5回

## 第5章 他人の情報との付き合い方

第1版は「イナゴ買いの完全排除」を勧めたが、事実はもう少し複雑である。

2025年の最大の勝ち (レーザーテック) は、アジイワシさんの見解がきっかけだった。本人も年次振り返りで「本気で信頼できる人を本気で探し、本気で信頼する、これも一つの手法」と書いている。日本精鉱 (アジイワシさん)、AIロボティクス (億り旬さん)、バイセル (ゆーさくさん) も他人起点の勝ちである。一方で、最悪の損失の多くも他人起点だった (ホープ・ダブスコ・テスラショート・保土谷・サンコール)。

勝ちと負けを分けたのは、他人起点かどうかではない。次の2点である。

1. **誰を、どこまで信じたか**: 熱量を持って調べ続けている人の、確信のある見解か。煽りや一時的な言及か。2023年の振り返りに本人の答えがある:「井村さん信じるなら徹底的に信じて持ち続けるしかない。そうじゃないなら買わない方がいい。つまりイナゴやるなら徹底的に」
2. **自分の確信に変換してから入ったか**: 時間軸と撤退条件を自分で決めたか。「戦略時間軸が違うのだから、何も考えずにINしてもだめ」(2022年の振り返り)。他人の取得単価と自分の立場は違う (2023/5/9)

したがって、ルールは「他人の情報で買うな」ではなく、**「信頼する発信者は少数に絞り、その人の見解で入るときも、自分で時間軸と撤退条件を書いてから入る」**が正確である。戦略宣言 (#363) がこの変換の場になっている。宣言なしの取引が負けているのは、変換を飛ばした取引が負けているということでもある。

フォローする投資家ごとの学び方は第1版の整理がおおむね有効である。ふみさんからは損切りの規律、おしおさん・ゆーさくさんからはチェンジ要素の発見、ごろんちゃんからは相場観を学び、売買のタイミングは真似しない。2023年に何度も「技量の差」と書いたケイさんの手法 (成長企業を中長期で持ち、下がったら買い増す) は、こすうけさん自身が「おれはケイさん寄り」と位置づけ (2023/5/9)、実際に2025年以降の長期保有の成績につながっている。

## 第6章 これからの指針

### 6.1 主戦場を一つに決める

データが示す主戦場は「**テーマの本流で、深掘りしたリーダーを、91日以上持つ**」である。2022年に本人が書いた「銘柄ごとにどちらで買ったか決めなければ」は、今は戦略宣言の仕組みとして実装されている。残る課題は、主戦場の外の売買を減らすことである。

- **短期売買は枠で隔離する**。やめられないなら、金額の上限 (例: 自己資金の5%) を決め、その中だけで行い、月次で別に損益を見る ([仕様レビュー_0927](../review/仕様レビュー_0927.md) 4-1)
- **大きい材料は玉を分ける**。コア玉は小さめのサイズで握り、売りの4分類でだけ売る。トレード玉は吹いたら利確する。3年間で4回たどり着いた結論を、型として固定する
- **保有銘柄は評価台帳に載っているものだけにする**。これで銘柄数の目安も自然に守られる

### 6.2 学びを発注の瞬間に出す

第3章の教訓を「覚える」必要はない。必要なのは、場面に応じて自動的に目の前に出ることである。

| 場面 | 出すもの | 仕組み |
|---|---|---|
| 新規に入るとき | 戦略と時間軸、撤退条件 | 戦略宣言 (#363) に、宣言なしの取引も月次レビューで必ず数える (#448 の最初の1行) |
| 決算が近いとき | 決算日と、決算前じり下げのフラグ | 決算カレンダーの事前ビュー (1保・2準・3監の全ステータス) |
| 急落した日 | 保有銘柄のRS順 | portfolio のRS列を弱い順に並べ、下から切る |
| 売るとき | 売りの4分類のどれか | 売却時に理由を選ばせ、「その他」は警告 |
| 約定した後 | 注文内容 | 普段使わない証券会社では建玉方向を二度確認 |

### 6.3 振り返りの形

本人の性質 (ルーティンが苦手、意味を感じない単調作業に消耗する) に合わせ、振り返りは短く・選ぶだけにする ([投資戦略.md](../投資戦略.md))。

- 毎回の投資メモは今のままでよい。日記として自由に書くことが、7年間続いている理由である
- 月次では、ルール違反と仮説外れを分けるだけにする。ルール違反だけが矯正の対象で、仮説外れは必要経費
- 四半期に一度、[教訓Top10](教訓Top10.md) を入れ替える。Top10 は「何年も繰り返している教訓」を発注前に見る形に圧縮したものである

## おわりに

7年分のメモを通して読むと、こすうけさんの最大の資質は、負けるたびに正しい結論へ自力で戻ってくることだと分かる。過去のメモに何年も後から書き込みを足している (「←24.9 オープンワークは23年一番くらう」) 投資家は、ほとんどいない。

第1版は「わかっているのに実行できない」を性格の構造問題とした。2025年以降の成績は、その見立てが半分しか正しくなかったことを示している。テーマ本流の銘柄を長く持つ場面では、こすうけさんはすでに実行できている。実行できていないのは、自分のエッジの外に出たとき、つまり場中・SNS・PTSで衝動的に動いたときである。

だから次の一手は、新しい教訓ではない。エッジの外に出る回数を減らすことと、何年も繰り返し書いてきた結論を、発注の瞬間に目の前へ出す仕組みである。どちらも、すでに Shintakane の中に土台がある。

## 付録: PTS反応の読み方 (2026年10月追補)

2026年10月4日、テラドローンに出た材料にPTSが反応しなかったのを「まだ気づかれていない」と読んで買い、翌日-5%となった。一方、2026年4月15日のボードルアは、決算にPTSが横ばいだったが場中で+15%まで上がった。見た目は同じ「PTSで無反応」だが、意味は逆である。

| | ボードルア (4/15) | テラドローン (10/4) |
|---|---|---|
| 材料の種類 | 決算の数字 (30%成長でPER20割れ) | ニュース・ヘッドライン |
| 本当に値付けする人 | 場中の機関 (バリュエーションで評価し直す) | PTSの個人 (材料に素直に反応する層) |
| 銘柄の注目度 | 地味で視聴率が低い | 個人に人気、手垢がついている |
| PTS無反応の意味 | 本命の評価者がまだ来ていない | 本命の評価者が見た上で見送った |

これは2026年7月9日のnote (好決算なのに反応が弱いところを買って下がった) と同じ構造で、**反応の弱さはそれ自体が市場からの情報**である。PTSで「まだ気づかれていない」と感じたら、「本当に良い材料なら、PTSで誰が先に買っているはずか。その人たちはなぜ買っていないのか」を自問し、具体的に答えられなければ見送る。PTS全般の条件ルールは [教訓Top10](教訓Top10.md) の #10 にまとめている。
