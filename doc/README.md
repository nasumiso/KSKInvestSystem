# ドキュメントガイド

このディレクトリには、Shintakane の利用・運用・設計に関する文書を置きます。
現行の動作はコードとテストを優先し、計画書・レビュー資料は作成時点の背景と判断を残す記録として扱います。

## 主要ドキュメント

| 文書 | 用途 |
|---|---|
| [システム概要](システム概要.md) | システムの目的、機能、スコアリングの概要 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | データフロー、DB、パス解決などの技術構成 |
| [COMMANDS.md](COMMANDS.md) | 開発・運用コマンドの一覧 |
| [OPERATIONS.md](OPERATIONS.md) | 運用機と開発機の役割、定常運用手順 |
| [TESTING.md](TESTING.md) | テスト方針と実行方法 |
| [MCP.md](MCP.md) | 提供中のMCP、制約、接続・運用への入口 |

## サブフォルダ

| フォルダ | 用途 |
|---|---|
| `plan/` | 進行中の機能変更に関する設計・実装計画、検討経緯、将来構想 |
| `decisions/` | 長期参照が必要な設計判断と、その理由・トレードオフ |
| `requirements/` | 実装の前提となる要件定義・仕様 |
| `review/` | UI/UX、設計、外部連携などのレビュー・検討資料 |
| `work/` | 調査、移行、運用作業の記録 |
| `screenshots/` | システム紹介などで長期保管する画像資産 |

新しい設計・実装計画は `doc/plan/` に置きます。実装完了後は、現行仕様を正規ドキュメントへ反映し、長期参照が必要な判断だけを `doc/decisions/` に残します。`doc/plans/` は廃止し、今後は使用しません。
