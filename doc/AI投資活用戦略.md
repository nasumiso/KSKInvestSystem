# AI投資活用戦略

## 基本方針: ハイブリッドdiscretionary

純粋クオンツでも純粋discretionaryでもなく、両者の良いとこ取りをする3層構造で運用する。

| 層 | 担当 | 役割 |
|---|---|---|
| **基盤レイヤー** | Shintakane（自作システム） | 定量化できる全て: スクリーニング、状態判定、数値集計、規律強制 |
| **分析レイヤー** | LLM AI | 定性判断の補助: 決算解釈、業界調査、多角的視点、競合比較、壁打ち |
| **判断レイヤー** | 自分 | 最終投資判断、戦略選択、規律遵守、長期学習 |

各層の責任が明確で、損失時に「どの層が悪かったか」を切り分けられる構造にする。

---

## なぜこのアプローチが有効か

- **AIの強み（大量処理・パターン検出・構造化）と人間の強み（定性判断・経営者評価・テーマ先見性）を能力分布通りに分業**できる
- カーネマンの知見: **「機械的スクリーニング → 人間が最終判断」が、純粋人間判断・純粋システム判断の両者を上回る**
- アルファディケイの影響を受けにくい: 優位性の源泉が「人間の定性判断 = 模倣困難な部分」にあるため、AIによる発見・消滅サイクルから守られる
- これは現代のトップティアファンドマネージャー（Bridgewater等）が実際に採用しているスタイル

## 注意すべき落とし穴と対策

### 1. 確証バイアスの増幅 🔴 最重要

AIに「強気材料を分析して」と聞けば強気材料を返し、「弱気材料を分析して」と聞けば弱気材料を返す。**問いかけ方によって自分の見たい答えを引き出してしまう**。

**対策**:
- 銘柄分析時は **必ず両側の視点を強制的に出させる**
- 例: 「この銘柄を買うべき理由3つと、買うべきでない理由3つを同じ詳細さで」
- プロンプトテンプレート化して常用する

### 2. AI への過信バイアス 🔴 認知特性的に最危険

AIの分析が高品質に見えると、自分の判断よりAIを信じたくなる。**特にINFP・低決断性31・高自責87のプロファイルでは、「自分で判断して間違えるよりAIに従って間違える方が心理的に楽」という構造的リスク**がある。

**対策**:
- AIの分析は「材料」として扱い、「結論」として扱わない
- 判断ログに「AIの分析」と「自分の判断」を**別欄で記録**する
- AIが結論を出してきても、最終判断は必ず自分で言語化する

### 3. ハルシネーション 🟡

LLMは事実を捏造することがある。特に業績数字の取り違え、存在しない出来事の生成、銘柄コードと企業名の取り違えに注意。

**対策**:
- 数値情報は必ず一次ソース（決算短信、四季報、株探）で照合
- AIは「分析の枠組み」を提供する役割にとどめ、「数値の根拠」は別経路で確認
- Shintakaneが数値収集、LLMが解釈、という分業を徹底

### 4. 「市場コンセンサス」を吐き出すリスク 🟡

LLMは学習データに含まれる**市場の多数派意見**を強く反映する。市場の多数派意見は**既に株価に織り込まれている**ため、それに従っても超過収益にはならない。

**対策**:
- AIの分析を「コンセンサスの確認」として使う
- 「自分の見方とコンセンサスがどこで違うか」を意識的に探す
- コンセンサスと一致するなら超過収益にはならない可能性が高いと認識

### 5. 自分で考える筋力の低下 🟡

「AIに補助してもらう」を続けると、自分で考える力が衰える。投資家適性スコア59/100の「分析能力」部分を維持するために対策が必要。

**対策**:
- 月に1-2銘柄は **AIに頼らずに分析する時間** を作る
- 定期的に「AIなし判断」の訓練を入れる

## このシステムで判断したいこと

ShintakaneとLLM AIを組み合わせる目的は、単に銘柄を探すことではなく、投資判断で迷いやすい論点を毎回同じ軸で検証することにある。特に以下を重点的に判断する。

- **この材料は本当に業績インパクトがあるのか**
  - 売上・利益・受注・稼働率・単価・市場規模のどこに効くのかを確認する
  - 一時的な話題性と、実際の業績変化を切り分ける

- **この上昇は実需かテーマ人気か**
  - 決算・受注・市況改善に裏付けられた上昇なのか、連想・需給・テーマ物色なのかを分ける
  - 実需なら中期保有、テーマ人気ならサイズと出口を厳しく管理する

- **どの情報が未織り込みか**
  - 市場がすでに評価している材料と、まだ十分に評価していない材料を分ける
  - コンセンサスとの差分、次の決算で数字に出る余地、説明資料・補足IR・経営者発信の含意を確認する

- **自分の投資仮説は前回からどう変わったか**
  - 新しい情報で強まった点、弱まった点、撤回すべき点を記録する
  - 「最初に買った理由」と「今も持つ理由」がズレていないかを確認する

- **同じ失敗を繰り返していないか**
  - 未調査の飛びつき、決算前じり下げの値ごろ買い、強い銘柄の早売り、弱い銘柄の放置、過剰分散を検出する
  - ルール通りの負けと、ルール違反の負けを分ける

- **今のポートフォリオは自分のリスク許容度に合っているか**
  - 保有銘柄数、主力比率、テーマ偏り、現金比率、決算跨ぎ量、レバレッジを確認する
  - 感情スコアとポジション量が逆方向になっていないかを確認する

## 運用ルール

### プロンプトテンプレートの整備

用途別に保存しておく:
- **決算分析用**: ガイダンスの読み取り、セグメント別含意、保守的か攻めか
- **業界比較用**: 競合とのバリュエーション・成長率比較
- **リスク分析用**: 弱気材料の強制列挙
- **セカンドオピニオン用**: 自分の判断の反対側を AI に主張させる

### 対話ログの保存

**AIとの対話ログを投資日記の一部として保存する**。これは:

1. AIの助言と自分の判断の差分を後から検証できる
2. 効果的だったプロンプトを再利用できる
3. 「最近AIに従いすぎていないか」を可視化できる
4. 5年分の投資日記資産に「AI時代の意思決定プロセスの記録」として加わる

フォーマット: `銘柄ID → AI対話ログ → 自分の判断 → 結果`

### Shintakane との分業

| タスク | 担当 |
|---|---|
| スクリーニング・指標計算 | Shintakane |
| 市場状態判定（FTD/DD等） | Shintakane |
| ベース構造検出（VCP/CWH等） | Shintakane |
| 数値集計・研究DB管理 | Shintakane |
| 売りシグナル・規律強制 | Shintakane |
| 決算文の解釈・含意読み取り | LLM AI |
| 業界トレンド調査 | LLM AI |
| 多角的視点の強制提示 | LLM AI |
| 競合比較・類似パターン検索 | LLM AI |
| 壁打ち・言語化補助 | LLM AI |
| **最終投資判断・サイズ・期間** | **自分** |
| **戦略選択・規律遵守** | **自分** |

## まとめ: Te機能外部化の発展形

このアプローチは MY_INVESTER_STRATEGY.md の「Te機能の外部化」を、AI時代に合わせて拡張するもの。

- **第1段階（既存）**: 定量計算をShintakaneに外部化
- **第2段階（本戦略）**: 定性分析の枠組みもAIに外部化、ただし最終判断は自分

Shintakaneを5年以上自作運用してきた技術的素地と、自己の認知バイアスを分析する習慣の両方を持っているのは、AI時代の個人投資家として構造的に有利な位置。問題は技術や戦略ではなく、結局のところ **規律の実行** に尽きる。これはAI時代でもアナログ時代でも変わらない投資の本質的課題。
