# 保有銘柄ダッシュボード 条件付き書式 ルール一覧

WebApp `/portfolio` の色分けロジック。スプシ「銘柄調査 - 保有銘柄」シートの条件付き書式 33 ルールから移植 (issue #177)。

## 実装場所

- **色定数**: `scripts/webapp/helpers.py` の `PORTFOLIO_COLORS`
- **判定関数**: `scripts/webapp/helpers.py` の `compute_cell_styles(row, today)`
- **ユニットテスト**: `tests/test_webapp_helpers.py::TestComputeCellStyles`

### 計算ロジック

#### 買い集めスコア (`_buy_collection_score_sum`)

```
A=5, B=4, C=3, D=2, E=1
"C,C" → 3+3 = 6 (色なし)
"A,B" → 5+4 = 9 → 濃黄
"D,D" → 2+2 = 4 → 水色
```

#### 時価総額カテゴリ (`_market_cap_category`)

```
< 100億    → "極小" (色なし)
< 400億    → "小"  (色なし)
< 1000億   → "中"  → 薄黄
< 3000億   → "大"  → 薄黄
≧ 3000億   → "特大" (色なし、"大" の完全一致なので "特大" は除外)
```

#### `<C3>` タグ判定

`gyoseki.get_gyoseki_quarity_expr(stock)` の戻り値文字列の末尾に `<C3>` が連結されていれば「3Q 連続利益率向上」マーカー。`stocks_shelve` には保存されておらず、表示時に都度計算する。

#### 更新日 M/D パース (`_parse_research_update_md`)

`row.memo.last_research_update` は `"4/27"` 形式 (年なし)。`today.year` を補完して date 化、ただし `today` より未来日になる場合は前年扱い。

```
TODAY = 2026/5/10
"4/27" → 2026/4/27 (13 日前 → 色なし)
"4/26" → 2026/4/26 (14 日前 → 薄灰)
"4/10" → 2026/4/10 (30 日前 → 濃灰)
"6/1"  → 2025/6/1 (前年扱い、約 11 ヶ月前 → 濃灰)
```

## 基準日について

色付け判定の基準日は `date.today()` を使用 (CLAUDE.md L28 規約「日付判定は `ks_util.get_price_day()` を使用」に対する明示的な例外合意済み)。

理由:
- 色付けは UI 視認性補助で、価格データ整合性 (`get_price_day` の本来用途) と無関係
- 「14日以上前 / 1ヶ月以上前 / 決算日±1ヶ月」の判定は日単位で十分な粒度、18:00 境界でズレても運用影響なし
- 価格データに連動する処理 (price.py / make_stock_db.py 等) では引き続き `get_price_day()` を使用

## ルール変更時の手順

スプシの条件付き書式を変更したら本ファイルも更新する:

1. Apps Script 再実行 → 新ダンプを取得
2. 差分を業務的に解釈して `compute_cell_styles` の対応箇所を更新
3. ユニットテストの境界値を新仕様に合わせる
4. 本ドキュメントの該当ルールも更新
