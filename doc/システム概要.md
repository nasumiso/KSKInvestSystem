# 成長株分析システム「Shintakane」

## はじめに

Shintakane は、日本株の中期ファンダメンタル投資を支える個人用のシステムです。
**AI で銘柄を当てるのではなく、自分の投資判断の再現性を高める**ことを目的にしています。
数値の収集と記録、保有銘柄の監視、規律の強制を Shintakane が担い、解釈は LLM、最終判断は人が行います。
目的と方向性の詳細は [方向性メモ](方向性メモ.md)、AI との分担は [AI投資活用戦略](AI投資活用戦略.md) を参照してください。

総合ランキングは「上位から発掘して買う」ためのものではなく、**候補を絞り込むフィルタと、保有銘柄の監視**に使います。

---

## できること

画面はブラウザで開く WebApp です (運用機で常駐し、自宅・出先から開けます)。

| 画面 | できること |
|---|---|
| 市場データ | 市場ステート (上昇確定 / 圧力下 / 調整)、指数、テーマランクと急浮上テーマの理由 (AI 調査)、市場の温度 (信用評価損益率・Fear & Greed 等) |
| 保有銘柄 | 保有・準保有・監視銘柄の一覧と色分け、防衛線 (損切り線・MA 割れ) のアラート、運用比率の目安、売買戦略・業態テーマの管理、証券会社CSVの取り込み |
| 決算・開示 | 保有・監視銘柄の決算発表と適時開示、決算後の株価反応 |
| 売買履歴 | 証券会社の約定から組み立てた売買エピソード、戦略別・年別の成績、判断ログ (アクションログ) |
| 銘柄詳細 | 決算ごとの業績・指標の時系列、四季報コメント、IR資料、IR問い合わせ回答、調査メモ |

ChatGPT や Claude からは MCP 経由で、四季報・IR問い合わせ回答・決算資料・銘柄評価台帳を参照できます。書き込めるのは銘柄評価台帳だけです ([MCP連携](MCP連携.md))。

## 毎日の自動処理

平日19時に次の順で実行します (東証の引け後、各種データが出揃うのを待つため)。

1. **新高値・出来高急増・決算発表の取り込み** — その日の注目銘柄を集め、日次発掘レポートを作る。市場ステートとテーマランクもここで更新する
2. **全銘柄のデータ更新とランキング** — 株価・業績・指標を取り直し、総合スコアで順位付けする。決算直後の銘柄は調査記録に業績のスナップショットを追記する
3. **運用比率の記録** — 市場ステートから今の運用比率の目安を出し、日々の実績と並べて残す
4. **急浮上テーマの調査** — 順位が急に上がったテーマの理由を AI が調べる
5. (金曜のみ) データベースの整理

### データの取得元

| 取得元 | 取得する情報 |
|---|---|
| 株探 | 新高値・出来高急増銘柄、業績、指標、テーマ、決算発表、適時開示、決算資料 (PDF) |
| Yahoo Finance | 日次の株価 |
| nikkei225jp 等 | 信用評価損益率、新高値・新安値、日経VI |
| 証券会社のCSV (手動で週次) | 約定履歴、残高 |
| 手入力 | 四季報コメント・業績予想、IR問い合わせ回答、調査メモ |
| ChatGPT との分析 | 銘柄評価台帳 (ファンダ・未織込・モメンタム・Valuation) |

## 独自のスコアリングシステム

本システムの核心は、4つの評価軸を組み合わせた**総合スコア（0〜100点）**です。

### 総合スコアの構成

```
総合スコア ＝ 業績（40%）＋ 指標（20%）＋ モメンタム（25%）＋ ファンダメンタル（15%）
```

| 評価軸 | 配分 | 見ているもの |
|--------|------|------------|
| **業績（Profit/Quality）** | **40%** | 過去5年間の増収増益の一貫性、直近四半期の成長率 |
| **モメンタム（Momentum）** | **25%** | 株価の相対的な強さ（TOPIX対比） |
| **指標（Value/Size）** | **20%** | 時価総額の適正さ、財務健全性（有利子負債比率） |
| **ファンダメンタル（Fundamental）** | **15%** | 市場で注目されている投資テーマとの関連性 |

---

### 各評価軸の詳細

#### 業績スコア（40%）— 成長の質と持続性

最も重視している評価軸です。一時的な好業績ではなく、**継続的に成長している企業**を高く評価します。

- **過去5年間の成長実績**（20点満点）
  - 年率7%以上の利益成長で満点、4%以上で半分の評価
  - 売上高の年率成長率（CAGR）も加味
  - 利益がマイナスだった年があれば減点

- **直近の利益成長率**（10点満点）
  - 直近年度の営業利益が前年比20%以上で満点

- **四半期ごとの成長トレンド**（最大70点）
  - 直近3四半期の売上・利益の成長率を個別に評価
  - 四半期単位で20%以上の利益成長、10%以上の売上成長があるほど高得点

**ポイント**: 「たまたま良い年」ではなく、四半期・年度を通じて安定成長している企業が高スコアになります。

#### モメンタムスコア（25%）— 市場からの評価

株価が市場平均（TOPIX）と比べてどれだけ強いかを統計的に評価します。

- **相対力指数（RS）の算出**: 13週・26週・39週・52週の株価変動率を加重平均
- **TOPIX対比の正規化**: TOPIXのRS値との比を、対数正規分布を用いて上位何%にいるかに変換してスコア化

**ポイント**: 単純な株価上昇率ではなく、「市場全体の動きと比べてどれだけ強いか」を測定します。市場全体が上がっている中での上昇は低評価、市場が下がっている中での底堅さは高評価になります。

#### 指標スコア（20%）— 投資適格性

時価総額と財務の健全性から、投資対象としての適格性を判定します。

- **時価総額の評価**（30点満点）
  - 最適ゾーン: 時価総額400億〜1,000億円（成長余地と流動性のバランス）
  - 小さすぎる（100億円未満）＝ 流動性リスク → 低得点
  - 大きすぎる（3,000億円超）＝ 成長鈍化の可能性 → 低得点

- **財務健全性**（±30点）
  - 有利子負債自己資本比率で判定
  - 0.5倍以下 ＝ 健全 → 加点
  - 3.0倍超 ＝ 財務リスク → 大幅減点

- **理論株価との乖離**
  - 5年間の予想利益から算出した理論株価との比較

**ポイント**: 日本市場の特性として、中型株（時価総額400億〜1,000億円）に最も大きな成長機会があるという考えに基づいた設計です。

#### ファンダメンタルスコア（15%）— 旬のテーマ

各銘柄が属する投資テーマ（AI、半導体、ヘルスケア等）の市場での注目度をスコア化します。

- 株探のアクセスランキングから日々のテーマ人気度を取得
- 人気テーマに属する銘柄ほど高スコア

**ポイント**: ファンダメンタルズだけでなく「今、市場が何に関心を持っているか」というセンチメント要因も取り入れています。

## テクニカル分析指標

スコアリング以外にも、以下の補助指標をレポートに含めています。

### トレンドテンプレート（7項目チェック）

機関投資家の買い集め局面に典型的な7つの条件をチェックします。

1. 株価が30週移動平均線＆40週移動平均線の上にある
2. 30週移動平均線が40週移動平均線の上にある
3. 40週移動平均線が1ヶ月以上上昇トレンド
4. 10週移動平均線が30週・40週移動平均線の上にある
5. 株価が10週移動平均線の上にある
6. 52週安値から30%以上上昇＆52週高値から25%以内にある
7. 相対力指数（RS）が70以上

**7点中何点か**で、上昇トレンドの質を一目で判断できます。

### 売り圧力レシオ（SPR）

日々の値動きと出来高から、買い勢力と売り勢力のバランスを推定します。

- 20日SPR / 5日SPR: 長期・短期の需給バランス
- 値が低いほど買い優勢（40%以下が目安）

### ポケットピボット

移動平均線付近で、過去の下げ日の出来高を上回る高出来高の上昇が発生した場合のシグナル。機関投資家の静かな買い集めを示唆するパターンです。

### ローソク足ボラティリティ

日中の値動きの大きさ（20日平均 / 5日平均）。ボラティリティが高まっている銘柄の識別に使います。

## レポートの見方

### 総合ランキング（code_rank.csv）

毎日更新されるランキングで、Google スプレッドシートにも反映されます。総合スコアと4軸の内訳、シグナル、トレンドテンプレート、売り圧力レシオ、業績・指標・理論株価、テーマ、保有状態などが並びます (列の正確な一覧は `make_stock_db.py` の `CODE_RANK_HEADERS`)。
普段は WebApp の各画面から同じ情報を見ます。

### 市場データ

市場ステート・指数・テーマランクは WebApp の「市場データ」画面で見ます。

### 日次発掘レポート（shintakane_result.csv）

その日に新高値や出来高急増を記録した銘柄の分析結果。「今日注目すべき銘柄」のリストです。

### 色の凡例 (保有銘柄の一覧)

| 色 | 意味 |
|---|---|
| 濃黄 / 薄黄 | 強く良い / 良い (順位が高い、RS が強い、割安、高配当 等) |
| 緑 | 株価的にプラス (需給・MA 乖離率が良い) |
| 赤 | 注目 (シグナル発生、「最」タグ、業績進捗の C3 等) |
| 薄赤 | 株価的にマイナス (需給・MA 乖離率が悪い)。月足の「月破」(低位からのブレイク) も薄赤で目立たせる |
| 青 / 水色 | 警告 / 弱い警告 (「売」/「警」タグ、ステージ2のコア条件割れ 等) |
| 灰 | データが古い (薄灰 14日以上、濃灰 1ヶ月以上) |

ステージ列は 2S = 濃黄、3S = 水色、4S = 青。列ごとの条件は `webapp/helpers.py` の `compute_cell_styles` を正とします。

## システムの設計思想

### なぜ業績を最重視するのか（40%）

短期的な株価変動ではなく、**企業の実力（＝利益の持続的成長）**を最も重要な判断基準としています。過去5年間の一貫した増収増益を評価するため、一過性の特需や会計上の操作では高スコアを得られません。

### なぜモメンタムを含めるのか（25%）

業績が良くても株価が反応していない銘柄は、まだ市場に認知されていないか、何かの理由で評価されていない可能性があります。モメンタムを加味することで、**市場が実際に資金を投じ始めている銘柄**を優先的に捉えます。

### なぜ時価総額を評価するのか（20%）

時価総額400億〜1,000億円の中型株ゾーンは、成長余地が大きく、かつ個人投資家が参入可能な流動性を持つ領域です。小型すぎる銘柄の流動性リスクと、大型すぎる銘柄の成長鈍化リスクの両方を回避します。

### 毎日の自動化

平日19時に自動実行される設計は、東京証券取引所の引け後（15:30）に十分な時間を置いてからデータ取得を行うためです。15:30の引け後に各種データが更新されるのを待ち、安定した最新データを取得します。

## 注意事項

- 本システムは投資判断の**参考情報**を提供するものであり、特定銘柄の売買を推奨するものではありません
- 過去の業績データに基づくスコアリングであり、将来の株価変動を保証するものではありません
- 投資に関する最終判断は、ご自身の責任において行ってください
