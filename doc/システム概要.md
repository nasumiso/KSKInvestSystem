# 成長株分析システム「Shintakane」

## はじめに

Shintakane は、日本株の中期ファンダメンタル投資を支える個人用のシステムです。
**AI で銘柄を当てるのではなく、自分の投資判断の再現性を高める**ことを目的にしています。
数値の収集と記録、保有銘柄の監視、規律の強制を Shintakane が担い、解釈は LLM、最終判断は人が行います。
目的と方向性の詳細は [方向性メモ](方向性メモ.md)、AI との分担は [AI投資活用戦略](AI投資活用戦略.md) を参照してください。

総合ランキングは「上位から発掘して買う」ためのものではなく、**候補を絞り込むフィルタと、保有銘柄の監視**に使います。

---

## できること

画面はブラウザで開く WebApp です (運用機で常駐し、自宅・出先から開けます)。

| 画面 | できること |
|---|---|
| 市場データ | 市場ステート (上昇確定 / 圧力下 / 調整)、指数、テーマランクと急浮上テーマの理由 (AI 調査)、市場の温度 (信用評価損益率・Fear & Greed 等) |
| 保有銘柄 | 保有・準保有・監視銘柄の一覧と色分け、防衛線 (損切り線・MA 割れ) のアラート、運用比率の目安、売買戦略・業態テーマの管理、証券会社CSVの取り込み |
| 決算・開示 | 保有・監視銘柄の決算発表と適時開示、決算後の株価反応 |
| 売買履歴 | 証券会社の約定から組み立てた売買エピソード、戦略別・年別の成績、判断ログ (アクションログ) |
| 銘柄詳細 | 決算ごとの業績・指標の時系列、四季報コメント、IR資料、IR問い合わせ回答、調査メモ |

ChatGPT や Claude からは MCP 経由で、四季報・IR問い合わせ回答・決算資料・銘柄評価台帳を参照できます。書き込めるのは銘柄評価台帳だけです ([MCP連携](spec/MCP連携.md))。

## 毎日の自動処理

平日19時に次の順で実行します (東証の引け後、各種データが出揃うのを待つため)。

1. **新高値・出来高急増・決算発表の取り込み** — その日の注目銘柄を集め、日次発掘レポートを作る。市場ステートとテーマランクもここで更新する
2. **全銘柄のデータ更新とランキング** — 株価・業績・指標を取り直し、総合スコアで順位付けする。決算直後の銘柄は調査記録に業績のスナップショットを追記する
3. **運用比率の記録** — 市場ステートから今の運用比率の目安を出し、日々の実績と並べて残す
4. **急浮上テーマの調査** — 順位が急に上がったテーマの理由を AI が調べる
5. (金曜のみ) データベースの整理

### データの取得元

| 取得元 | 取得する情報 |
|---|---|
| 株探 | 新高値・出来高急増銘柄、業績、指標、テーマ、決算発表、適時開示、決算資料 (PDF) |
| Yahoo Finance | 日次の株価 |
| nikkei225jp 等 | 信用評価損益率、新高値・新安値、日経VI |
| 証券会社のCSV (手動で週次) | 約定履歴、残高 |
| 手入力 | 四季報コメント・業績予想、IR問い合わせ回答、調査メモ |
| ChatGPT との分析 | 銘柄評価台帳 (ファンダ・未織込・モメンタム・Valuation) |

## スコアリングの考え方

全銘柄に**総合スコア (0〜100点)** を付けます。候補の絞り込みと保有銘柄の監視に使うもので、上位を機械的に買うためのものではありません。

| 評価軸 | 配分 | 見ているもの | なぜこの重さか |
|---|---|---|---|
| 業績 | 40% | 5年間の増収増益の一貫性と、直近の四半期・年度の成長率 | 一過性の好業績ではなく、**利益の持続的な成長**を最も重視するため |
| モメンタム | 25% | 株価の強さを TOPIX と比べた相対値 (上位何%か) | 業績が良くても株価が反応していない銘柄より、**市場が資金を投じ始めた銘柄**を優先するため |
| 指標 | 20% | 時価総額 (中型株を高く評価)、財務健全性、理論株価との乖離 | 成長余地と流動性を両立する**中型株**を狙い、財務リスクの高い銘柄を避けるため |
| ファンダメンタル | 15% | 属する投資テーマの、いまの人気度 | 市場の関心を取り込みつつ、**振り回されない程度**の重さに抑えるため |

点数の細かい配分は `make_stock_db.py` を正とします。ChatGPT で付ける**銘柄評価台帳の点数 (ファンダ・未織込・モメンタム・Valuation) とは別物**です ([用語集](用語集と不変条件.md))。

### 補助の指標

| 指標 | 何を見るか |
|---|---|
| トレンドテンプレート | 移動平均線の並び・52週高値からの位置・RS の7項目チェック。7点中何点かで上昇トレンドの質を見る |
| 売り圧力レシオ (SPR) | 値動きと出来高から推定した買い・売りのバランス (20日・5日)。低いほど買い優勢 |
| ポケットピボット / ブレイクアウト | 移動平均線付近での高出来高の上昇。機関投資家の買い集めを示唆する |
| ローソク足ボラティリティ | 日中の値動きの大きさ (20日・5日平均) |
| 防衛線 | 保有銘柄の損切り線と、戦略ごとの移動平均線割れ |

## レポートの見方

| レポート | 中身 | 見る場所 |
|---|---|---|
| 総合ランキング (`code_rank.csv`) | 総合スコアと4軸の内訳、補助の指標、業績・指標・理論株価、テーマ、保有状態 (列の一覧は `CODE_RANK_HEADERS`) | WebApp、Google スプレッドシート |
| 日次発掘レポート (`shintakane_result.csv`) | その日に新高値・出来高急増を記録した銘柄の分析結果 | Google スプレッドシート |
| 市場データ | 市場ステート、指数、テーマランク、市場の温度 | WebApp の「市場データ」 |

### 色の凡例 (保有銘柄の一覧)

| 色 | 意味 |
|---|---|
| 濃黄 / 薄黄 | 強く良い / 良い (順位が高い、RS が強い、割安、高配当 等) |
| 緑 | 株価的にプラス (需給・MA 乖離率が良い) |
| 赤 | 注目 (シグナル発生、「最」タグ、業績進捗の C3 等) |
| 薄赤 | 株価的にマイナス (需給・MA 乖離率が悪い)。月足の「月破」(低位からのブレイク) も薄赤で目立たせる |
| 青 / 水色 | 警告 / 弱い警告 (「売」/「警」タグ、ステージ2のコア条件割れ 等) |
| 灰 | データが古い (薄灰 14日以上、濃灰 1ヶ月以上) |

ステージ列は 2S = 濃黄、3S = 水色、4S = 青。列ごとの条件は `webapp/helpers.py` の `compute_cell_styles` を正とします。

## 注意事項

- 本システムは投資判断の**参考情報**を提供するものであり、特定銘柄の売買を推奨するものではありません
- 過去の業績データに基づくスコアリングであり、将来の株価変動を保証するものではありません
- 投資に関する最終判断は、ご自身の責任において行ってください
