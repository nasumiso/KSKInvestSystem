# 日本版 F&G の5区分は、CNN と同じ頻度で出る閾値にする

- Status: Accepted
- Date: 2026-11-27
- Related: [日本版 F&G 仕様](../spec/日本版FearGreed仕様.md)、[資金管理の検証](../投資メモ分析/レビュー/資金管理の検証_2026-11.md) の 8・9、#524、#593

## Context

日本版 F&G の5区分 (25 / 45 / 55 / 75) は CNN の数値をそのまま借りていた。日本版は各成分を直近2年の分位にして平均するので、合成値の分布は成分の点の付け方・成分どうしの連動・成分の数で決まり、CNN とは違う。同じ閾値でも区分の出る頻度が違った (CNN 2021〜: Extreme Fear 14% / Fear 33% / Neutral 16% / Greed 31% / Extreme Greed 5%、日本版の同じ期間: 16 / 21 / 13 / 41 / 10%)。

ユーザーの使い方は、Extreme Fear・Extreme Greed を感情的な売買が入りやすい局面の合図 (逆張りで感情に逆らう)、それ以外を順張りの局面とすること。CNN と同じ目的の区分にしたい。

## Decision

- **5区分の境目を 25 / 51 / 57 / 77 にする** (`fear_greed_jp.RATING_EDGES`)。CNN の日次 (2021-01-22〜2026-11-27、1471日) で各区分の下に入る累積割合 13.9 / 47.2 / 63.2 / 94.6% を、本番と同じ5成分の日本版 (2025-10-28〜、263日) の分位点に当てた値 (24.8 / 51.5 / 56.7 / 77.1)
- 区分の判定は `fear_greed_jp._rating` の1か所にし、market ページ・保有銘柄タブ・今日のアクションの「準備」・保有の点検 (#589) のきっかけが同じ境目を使う。market ページの各成分の色も同じ境目
- 5成分は約1年分なので暫定。2年分たまる 2027年秋に `python money_rule_sim.py fng` の「5区分の境目」で出し直す

## Rationale

| 採用しなかった案 | 理由 |
|---|---|
| 今のまま (25 / 45 / 55 / 75) | 数値は CNN と同じでも、出る頻度が違うので区分の意味が CNN と違う。日本版の Greed は日数の約4割、Extreme Greed は CNN の2倍出る |
| その後の値動きが一番分かれる値で決める | 2005〜 の日次で、点数の帯ごとの3か月後の日経平均は +1〜+4% の間でばらつくだけで、点数と向きの関係がない (荒れ方は 20未満で大きくなる)。合わせ込むとノイズに合わせることになる |
| 頻度を自分で決める (Extreme 10% / その外 20% / Neutral 40% など) | CNN と同じ目的の区分にしたいので、頻度も CNN に合わせる。頻度を自分で選ぶと、その根拠がまた要る |
| 成分ごとの点の付け方を CNN に寄せる | CNN の成分の式は公開されていない。合成値の分布で頻度を合わせれば、成分の付け方・連動・数の違いはまとめて吸収される |

3成分で作り直した長期 (2005〜2025-10、5094日) の同じ分位点は 20.5 / 52.0 / 61.3 / 80.5 で、5成分より高い側に広い (成分が多いほど平均が50に寄る)。本番の5成分の分布を使う。

## Consequences

- 区分の頻度 (5成分の期間) は CNN とそろう: Fear が 22→33%、Neutral 21→16%、Greed 35→31%、Extreme Greed 8→5%。Extreme Fear (25未満) は変わらない
- #589 の Extreme Greed のきっかけは 75→77 で少し減る。今日のアクションの「準備」は変わらない
- `money_rule_sim.py` の過去の検証 (資金管理の検証 §1〜8) は旧境目で測った。出し直すと Fear/Neutral と Extreme Greed の境目が変わるが、採用したルールは F&G を量に使わないので判断は変わらない
- 見直す条件: 2027年秋の出し直しで境目が2点以上動いたら置き換える。成分を足す・外す・点の付け方を変えたら、そのとき出し直す
