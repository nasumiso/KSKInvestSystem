# ブは本来のブレイクアウトの条件で出し、ベースの形の検出器は作らない

- Status: Accepted
- Date: 2026-11-12
- Related: #578、#340 (閉じた)、#109・#111・#116 (#340 に統合済み)

## Context

ブ (`breakout`) はミネルヴィニ・オニールのブレイクアウトを日々の値動きから検知する意図のシグナルだが、条件は「出来高が30日平均の1.5倍以上 (またはストップ高) で、前日より高く引け、10日MA からの乖離が5%以内」で、価格の上抜けを見ていなかった。トレンドは、週足の7条件がすべて不合格 (ステージ4) の銘柄を除くだけ。今日のアクションにブが1日40件以上出て埋もれていた。

#340 は、VCP の検出・ピボット価格の保存・新しい記号 `[BP]`・ピボットのゾーン表示・カップ・ウィズ・ハンドルを作る計画だった。作る前に、どの条件がブレイクアウトの質を上げるのかを過去の日足で確かめた。

### 検証

過去の日足に今の判定を当てて再現し、その日の終値で買って30日以内に +10% と −7% のどちらに先に届くかを数えた。数字は「+10% に先に届いた割合 − −7% に先に届いた割合」の、基準 (何もない日) との差。プラスなら基準より有利。

- A = 管理中の約320銘柄 (保有・準保有・監視。今選んでいる銘柄なので良い側に偏る)、B = それ以外から無作為に選んだ800銘柄のうち売買代金の中央値が3千万円以上の約700
- 期間は5年。前半 = 〜2024/10、後半 = 2024/11〜。連日のシグナルは最初の1件だけ数えた
- ステージ2と52週の範囲は、本番の週足の条件を日足に換算した (30週MA ≒ 150日、40週MA ≒ 200日)

| | B 前半 | B 後半 | A 前半 | A 後半 |
|---|---|---|---|---|
| 今のブ | −1.1 | −1.6 | +2.0 | +2.3 |
| 本来のブ (20日高値抜け + ステージ2 + 52週の範囲) | −4.6 | +6.7 | +3.9 | +4.9 |
| 本来のブ + 出来高2倍以上 | −0.6 | +7.5 | +8.1 | +8.3 |
| 本来のブ + 直前10日の値幅10%未満 + 出来高2倍以上 | +0.7 | +11.1 | +10.9 | +14.5 |
| 本来のブで直前10日の値幅12%以上 | −7.0 | −10.5 | −4.2 | −0.6 |
| 週ブ 全体 | −2.4 | +2.8 | +4.2 | +2.6 |
| 週ブだけ (直近5日に今のブなし) | −3.5 | −14.0 | +6.3 | +11.2 |

- 今のブには、どの切り口でも優位性が無い
- 本来のブは今のブより良いが、時期と銘柄に左右される。無作為の銘柄の前半は基準より悪い
- 直前の値動きが締まっていて出来高が2倍以上のブは、4区分すべてで本来のブより良い。値幅は狭いほど良い (8% > 10% > 12% > 15%)
- 高値を見る日数は 20〜50日でほぼ同じ (管理中の2年分での比較)
- TOPIX が50日・200日MA を下回る時期の本来のブは、基準より悪い (B −9.4、A −7.4)

## Decision

- **ブ**: 検知 (`price.py`) は変えず、表示の条件を3つ足す。終値が直前20日の終値の高値を上抜け / 週足のステージ2 (中核3条件。ポと同じ集合) / 52週の範囲 (`high(low)52`)
- **ブ+**: ブのうち、直前10日の値幅が前日終値の10%未満で、出来高が30日平均の2倍以上のもの
- **条件から外れた出来高急増**は、詳細チャートに中抜きの◇でだけ出し、ツールチップに外れた理由を出す
- **今日のアクション**はブをすべて出し、ブ+ を先に並べる
- **週ブは変えない**
- 閾値の判定は解釈層 (`make_stock_db`) に置く。検知時に「高値を上抜けたか」と「直前10日の値幅」を保存し、条件を変えても再取得が要らないようにする
- ブは単独の買いシグナルではなく、調べ済みの銘柄が動いた日に気づくための印として扱う

## Rationale

| 採用しなかった案 | 理由 |
|---|---|
| VCP の検出器 (#340 Phase 2) | 簡易な判定では、管理中と無作為、前半と後半で符号が変わる。#340 自身が「工数の本丸は閾値の調整」としており、調整すれば効くという証拠が無い |
| カップ・ウィズ・ハンドルの検出器 (#340 Phase 3) | 該当が51〜99件と少なく、管理中と無作為で逆の結果 |
| ピボット価格の保存と、買い場・高値追いのゾーン表示 | ピボットから5%以内のほうが良いという結果が出ない (10%以上伸びた日のほうが良い) |
| 新しい記号 `[BP]` をブと並べる | ブ自体を20日高値の上抜けにするので役割が重なる |
| ベースの長さ・深さ、出来高の枯れ、引けの位置を条件にする | 一貫した傾向が無い (出来高の枯れは3区分で改善、無作為の前半で悪化。引けの位置は逆の結果) |
| 出来高の強さだけで絞る (11/11 に入れた「ブ(中)以上」) | 今のブの中では強さで差が出ない。効くのは本来のブの中での「締まり + 2倍以上」 |
| 週ブを「ブが出ていない銘柄」に絞る | 管理中の銘柄では良いが、無作為の銘柄では基準より悪い |
| 高値を50日で見る | 20日と差が無く、日足の取得 (約60日) を延ばす必要が出る |
| 底値圏の出来高急増を別シグナルにする | 200日MA の下で出た今のブは基準より悪い (管理中の2年分での比較) |

## Consequences

- 調整局面ではブがほとんど出なくなる。2026-11-12 の実データでは、管理中の銘柄で直近10日に検知した227件のうち条件を満たすのは11件、ブ+ は0件 (急落の直後で、ステージ2と52週の範囲から外れた銘柄が多い)。出来高の急増そのものはチャートの◇で見える
- ステージ2と52週の範囲は、発生日ではなく今のトレンドテンプレートで見る。ブのあとに崩れた銘柄は、ブが消えて◇になる
- 検証の限界: 対象は今上場している銘柄だけ。VCP・カップ・ウィズ・ハンドルは簡易な判定での結果で、丁寧に作れば違う可能性は残る。最初に管理中の2年分だけで測ったときは本来のブの差が +8 前後に見えたが、対象と期間を変えると上の表まで縮んだ
- 2026年12月末の仕様レビューで、反映後に出たブ・ブ+・週ブのその後の値動きを確かめる。シグナルの履歴が残らないので (#343)、確かめるには過去の日足から再現する
