# 日経VI が30を超えている間は、運用総額を0.8倍までに抑える

- Status: Accepted
- Date: 2026-11-27
- Related: #610、#594、[資金管理の検証](../投資メモ分析/レビュー/資金管理の検証_2026-11.md) の 5、[2026-11-26 の判断](2026-11-26-運用総額はふだん一定で口座の上限をかけ信用評価損益率の底で買い向かう.md)、[投資戦略.md](../投資戦略.md) の「張れる量」

## Context

2026-11-26 の判断では、変動の大きさで張れる量を抑える案 (日経VI・口座の下方ボラ) を採用しなかった。ところが日経VI の上限は「1週で 3σ 動いても追証に届かない倍率」として作ったため緩すぎて、一番低い週でも 2.66倍と一度も 1.2倍を下回らず、仕組みが発動していなかった。下方ボラの上限も、抑える先が 1.0倍で週1段だったため効きが小さかった。
VI で減らす目的は、リターンではなく、下げが何週も続く暴落の最終局面を避けること (テール) だった。

## Decision

- 金曜 (週の最後の行) の引けで日経VI が 30 を超えたら、25 を下回るまで、運用総額を **0.8倍まで**に抑える
- 抑えるときは、その週に 0.8倍まで下げる (週1段ではない)。外れたら、いつもどおり週1段で戻す
- 信用評価損益率の底で買い向かっている間 (1.6倍の3か月) は抑えない。口座の上限は効く
- 2026-11-27 より前の判定日には当てない (過去に出した目標を変えない)

## Rationale

日経平均 2001〜 と 2009〜、保有 2025-01〜 で、最終案に重ねて比べた (`money_rule_sim.py vi`)。平均倍率が下がるだけで下落は浅くなるので、平均倍率が近い「ふだん 1.1倍」と比べた。

- 2001〜 (リーマンを含む): 口座の上限だけ 63.9% → 58.8% (最大DD)、最悪の1か月 −37% → −33%、年率は落ちない。ふだん 1.1倍 (62.1%・−37%) より浅い
- 2009〜 (リーマンを含まない): ふだん 1.1倍とほぼ同じ。口座の上限が、下げが続く局面の大半を受け持っている

| 採用しなかった案 | 理由 |
|---|---|
| 週1段で 0.8倍へ下げる | 1.2倍から 0.8倍まで3週かかり、コロナでは抑えない版より悪かった |
| 買い向かいの間も抑える | 底の合図は VI が高い時期に出やすく、1.6倍の週が 121 → 102 に減り、年率が 1.3pt 落ちた |
| VI が上がるにつれて段階的に抑える (20〜25 で 1.1倍、25〜30 で 1.0倍など。比例型も) | 日経VI は中央値が約23 で、20〜25 はふだんの水準。20 から抑えると約7割の週で抑え、ふだんの倍率を下げたのと近くなり年率が 0.3〜1.8pt 落ちた。日経VI の水準に置き直した段 (VIX の 20・25・30 と同じ分位の 25・30・35) は二択とほぼ並ぶ (年率 +0.1〜0.4pt、最大DD 0.3〜0.4pt 深い) が、2026年の半導体の暴落と保有では二択より深く、目的のテールでは二択が勝った (検証の 5) |
| VI 40超で抑える | 減らすのが下げの後半になり、年率が 0.5pt 落ちた |
| VI の急騰 (20日平均の1.5倍) で抑える | 効かなかった |
| 下方ボラで 0.8倍に抑える (代わりに、または両方) | 0.8倍にすれば効くが、2009〜 で最大DD が VI より深く、両方使っても VI だけより 0.1〜0.4pt しか浅くならない。結果を見る前に決めた基準で VI だけにした |
| ふだんの倍率を 1.1倍に下げる | 2009〜 では同じくらいだが、2001〜 ではリーマンで VI のほうが浅い |

## Consequences

- 量の決定の材料は、口座の資産・信用評価損益率・日経VI の3つになる
- すぐ戻る急落 (2024-08・2025-04) では、VI が跳ねたあとに減らし、戻りを 0.8倍で受けるので、毎回少し損をする
- 証拠の中心はリーマンと 2026年の半導体の暴落の2回だけ。2026年は VI 30超の日が 64% あり、保有の期間の結果はこの1年に引っぱられている
- `nikkei_vi.json` は直近30日分しか残らないので、VI が 25〜30 に6週以上とどまると状態が分からず、抑えない側に倒れる
- 見直す条件: VI 30超で抑えたあとの局面 (急落ですぐ戻ったか、下げが続いたか) を、次の成果レビューで確かめる
