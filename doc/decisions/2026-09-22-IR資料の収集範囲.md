# IR資料の収集範囲: 決算資料は株探から自動、中計は半自動、OCR はしない

- Status: Accepted
- Date: 2026-09-22
- Related: #139, #457, #433

## Context

LLM (MCP 経由の ChatGPT/Claude) でファンダメンタル分析をするため、決算短信・決算説明資料・中期経営計画を一次情報として集め、テキスト化したい。

## Decision

- **決算短信・説明資料は株探だけから自動で集める**。PDF は株探の開示URLを機械変換して直接取得し、HTML はパースしない。TDnet へのフォールバックは作らない
- 収集深度は直近1件を必須 (失敗は ERROR)、直近1年を既定とする
- テキスト品質を `ok` / `garbled` / `image_based` の3値で記録する。**OCR は実装しない**
- **中期経営計画は適時開示経路では取れないため、会社IRページから半自動で集める** (候補提示 → ユーザー選択 → 確定DL)。全自動クロールは作らない
- 中計の `date` は常に推定値 (`date_estimated: true`)。**中計の `is_latest` は自動で落とさず**、旧版化はユーザーの明示操作 (`mark-superseded`) のみ

## Rationale

- 株探だけで1年分揃うことを実測で確認した。URL 変換なら HTML 変更で壊れる箇所が無い
- 画像主体・文字化けの資料は ChatGPT に PDF を直接添付すれば読める (実機確認済み)。OCR の重い依存を持ち込む必要がない
- 企業IRサイトは構造が銘柄ごとにばらばらで、全自動探索は作り込みのコストに対して精度が読めない
- 推定日付を根拠に旧版を非最新化すると、古い中計を最新として扱い正しい資料を隠す。また index.json を決算資料と共有しているため、自動更新を誤ると決算資料まで MCP から消える

## Consequences

- `text_quality=ok` は「分析に使える」の保証ではない。グラフ内の数値が落ちることがある (その場合は PDF を見る)
- 同じ銘柄に中計が複数並立しうる。どれが現行かは内容から判断する
- 中計の手動確定が面倒になったら自動化を再検討する
