# 月次の売買振り返りは、取引ごとの照合と2つの弱点仮説に絞る

- Status: Accepted
- Date: 2026-10-11
- Related: #448、[.claude/skills/trade-review/SKILL.md](../../.claude/skills/trade-review/SKILL.md)、[投資戦略.md](../投資戦略.md)

## Context

月次の振り返り (#448) の当初案は、投資スタイルを6軸 (銘柄選択・リターン源泉・タイミング・テーマ・ポジション管理・規律) に整理し、売買履歴と保有PFの両方を全軸で「遵守 / 逸脱 / 判定不能」に判定するものだった。完成形を想像できなかったので、実装の前に 2026年9月の実データで節ごとの見本を作り、ユーザーが1節ずつ要否を決めた。

## Decision

- レポートは、数字サマリー / 取引ごとの照合 / 弱点仮説の検証 / 保有PFの点検 / 問い / ルール候補 の6節にする。6軸の全軸判定はしない
- 取引ごとの照合の対象は、当月に完全決済したエピソードと、当月に新規に建てたエピソード
- 弱点仮説は「損切りの幅」と「売ってすぐ買い直す」の2つを、年初来の累計で見る
- 保有PFは、運用比率・銘柄数・小口・損切り原則を超えた含み損だけを見る
- `/trade-review` はセッション内の対話にする。問いには選択肢で答え、ルールの選択と保存まで1回で終える
- ルール候補は、翌月の JSON の数字で守れたかを確かめられるものに限る
- 保有PFの遷移を追う専用の履歴は作らない。月次の JSON に銘柄別の保有一覧を入れる

## Rationale

9月の見本で指摘が出たのは、市場局面別の売買額 (調整判定の日に買い越し)、取引ごとの逸脱 (損切りした銘柄を13日後に高く・大きく建て直す)、損切りの幅、再IN だった。戦略別・テーマ別の集計は「良い月だった」以上のことを言わなかった。

| 採用しなかった案 | 理由 |
|---|---|
| 6軸の全軸判定 | 月に十件前後の決済では、軸ごとに分けると判定不能が並ぶ。指摘が出た節は軸の区分と対応していなかった |
| 戦略別・テーマ別の月次集計 | 月9件を5戦略に割ると1戦略1〜3件。年別の集計は `/trade-history` にある |
| 月次の実現損益に TOPIX 騰落率を併記 | 実現損益は決済した月に計上され、その月の指数と対応しない (155日保有の利益が1ヶ月の指数と並ぶ) |
| 弱点仮説を当月分だけで検証 | 件数が足りない |
| 損切りの遅れを保有日数で測る | 2026年1〜9月は、負けの保有日数の中央値が14日、勝ちが34.5日で、日数では成り立たなかった。損失の65%は損益率 −10% を下回った36件から出ており、遅れは幅に出ている |
| 取引の対象を完全決済だけにする | 売ってすぐ買い直す動きが、取引の節に出てこない |
| `claude -p` でレポートだけ作り、回答は振り返りメモに書く | 振り返りは短く・選ぶだけにする方針 (投資戦略.md)。詳しい反省は投資日記に書かれている |
| 保有PFに防衛線・テーマの集中を載せる | 保有銘柄タブで毎日見えている |
| 保有PFの日次スナップショット | 過去の株数は約定から、株価は yfinance から、全体の運用比率は `exposure_log.json` から戻せる。月次レビューは時点値しか使わない |
| 含み損が大きい銘柄の通知を足す | 2780 は 9/3 から防衛線 (防) が出たまま1ヶ月以上保有していた。足りないのは通知ではない |

## Consequences

- 月次の md / JSON (`$KS_DATA_DIR/trade_review/`) が、問いへの回答・選んだルール・その月の保有PFの唯一の記録になる。既にあれば書かない
- 自己申告の感情スコアは記録していないので、「調整局面の買い越しは方針どおりか」は月次の問いで思い出して答えるしかない。日々のスコアを残すかは #480 で判断する
- 含み損の閾値は投資戦略.md の原則 (−10%) を一律に使う。戦略マスターの損切り幅 (中長期ファンダ 25%、GARP 20% など) とは別の線で、戦略ごとの線は防衛線が見ている。両者の食い違いをどう揃えるかは未決
- 再検討の条件:
  - 月次レビューで決めたルールが、翌月も数字で「守れていない」と出たら、そのルールだけを仕組みにする (再INの警告、−10% 超の保有に理由を書かせる欄が候補)
  - 約定からは出せない保有の遷移の問いが実際に出たら、保有PFの履歴を検討する
  - 2〜3回回して使わなかった節は外す
