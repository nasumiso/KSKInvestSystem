# 信用評価損益率を、F&G と重ねない逆張りの材料に加える

- Status: Accepted
- Date: 2026-10-28
- Related: #535、[2026-10-24 の判断](2026-10-24-運用比率の目標は感情スコアとFGの逆張りで推定維持率から出す.md)、[推定維持率仕様](../spec/推定維持率仕様.md)

## Context

10/24 の判断で、運用比率の目標の段は「感情スコアが主、日本版 F&G の Extreme で逆張り 1 段、それ以外は市場ステートで攻める側に上限」とした。信用評価損益率 (信用買い建玉の平均含み損益率、週次) は取得して日次ログに残していたが、指標を増やすと効果を検証しにくくなるので判定には使っていなかった。ユーザーはこの指標を信頼できると考えており、F&G と同じく感情を補正する材料にしたい。

## Decision

- 信用評価損益率が −3% 以上 (天井圏) なら +1 (守る側)、−15% 以下 (底値圏) **かつ前週より改善**なら −1 (攻める側)
- **F&G とは重ねない**。同じ向きなら 1 段だけ、逆向きなら打ち消して 0 とし、市場ステートの上限をかける
- /market の評価列は F&G と同じ5区分・同じ配色にする (天井圏 / 強気 −6%超 / 中立 −10%超 / 弱気 −15%超 / 底値圏)。弱気・底値圏で前週より改善した週は印を付ける

## Rationale

| 採用しなかった案 | 理由 |
|---|---|
| F&G と足し合わせる (両方 Extreme で 2 段) | どちらも市場の心理を測る指標で、同じ材料を二重に数える。感情 −2 と重なると目標が維持率 50% を下回る水準まで振れる |
| 底値圏も水準だけで −1 | 底で早く張ると −20〜−25% まで突き抜けたときにレバレッジをかけたまま実損になる。天井で早く落とすのは機会損失で済む。痛みが非対称なので底の側だけ反転を待つ |
| 12月末の見直しまで入れない | `step_parts` に信用で動いたことが残るので、10/24 の判断の検証は信用が効いた日を分けて行える。信用だけが Extreme で F&G が Extreme でない日は多くない見込み |

## Consequences

- 閾値 (−3 / −6 / −10 / −15) は一般的な目安で、自前データ (2026-03〜、30 週) には −15% 以下の週がまだ無く校正していない。2026-12 末の仕様レビューで値の分布と合わせて見直す
- 週次で数日遅れの指標なので、補正は1週間単位でしか変わらない
