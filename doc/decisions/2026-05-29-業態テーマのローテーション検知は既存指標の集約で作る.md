# 業態テーマのローテーション検知は既存指標の集約で作る

- Status: Accepted
- Date: 2026-05-29
- Related: #283, #155, #282

## Context

株探テーマの `theme_rank` は市場の自動分類でローテーションを見る。自分が付けた業態テーマ (手動分類) でも同じことをしたい。中長期のリーダーシップ (slow) と、短期の勢い (fast) の両方が要る。

## Decision

- 業態テーマ別サマリー (`/portfolio/themes/summary`) は、構成銘柄の既存指標を等加重で集約する。テーマ指数は作らず、DB にも書かない (リクエストごとに計算)
  - slow: `momentum_pt` の平均・最大。MarketSmith の Industry Group Rank (3/6/9/12ヶ月加重の相対パフォーマンスをパーセンタイル化) と同じ構成になる
  - fast: RSラインの A / B (直近5日・20日平均との乖離率) の平均
- RSラインの A / B を「N日前の1点との比」から「N日平均との乖離率」に変えた。code_rank のモメンタム列と銘柄詳細の tooltip も同じ定義にそろえた
- 構成銘柄が1つのテーマも表示する

## Rationale

- 1点比較は、今日か N日前のどちらかがヒゲ・急変だと値が大きくぶれる。平均を基準にすると、ぶれが 1/N に薄まる
- **Blue Dot (RSライン新高値) のグループ集計は採用しない**。MarketSmith の Blue Dot は個別銘柄のチャート機能で、グループ単位の Blue Dot は無い。テーマ単位に集約すると独自の breadth 指標になり、複雑さに見合わない
- **`momentum_pt` の日次履歴を永続化して傾きを見る案 (グループランクの時系列変化に最も忠実) は保留**。`momentum_pt` は最新値しか持たず、過去時点の再計算には当時の TOPIX rs_raw と calib が要る。永続化すると「DB に書かない」方針も崩れる

## Consequences

- RSラインの A / B は符号が「勢いの一服」を表し、上昇トレンド中でも負になりうる
- テーマの同義語・誤字は別テーマとして集計される (テーママスター #282 で抑える)
- **見直し条件**: 乖離オシレーターではローテーションを捉えにくいと感じたら、`momentum_pt` 履歴の永続化を別 issue で検討する
