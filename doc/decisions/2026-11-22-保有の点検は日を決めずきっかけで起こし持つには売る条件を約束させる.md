# 保有の点検は日を決めずにきっかけで起こし、持つには売る条件を約束させる

- Status: Accepted
- Date: 2026-11-22
- Related: #589、#448 (月次の振り返り)、#587、[.claude/skills/portfolio-review/SKILL.md](../../.claude/skills/portfolio-review/SKILL.md)、[投資戦略.md](../投資戦略.md)

## Context

2026年10〜11月の半導体の暴落で、損切り幅を超えた建玉を持ち越し、ポートフォリオが崩れた (11/13 時点で保有21銘柄のうち10銘柄が幅超え)。2026-11-15 に、幅超えの銘柄を AI との対話で1回仕分けた (「今日ゼロからこの値段で買うか」)。本人の評価は高かったが、11銘柄のうち9銘柄が「持つ」になり、決めたことはどこにも保存されず、実行されたかも照合されなかった。

月次の `/trade-review` の「保有PFの点検」は月に1回・表だけで、行動に繋がっていなかった。いま持っている建玉を点検し、決めたことを次回に約定で照合する `/portfolio-review` を作るにあたって、頻度・「持つ」の条件・台帳の扱いを決めた。

## Decision

- **点検の日を決めない**。平時はやらない。前回の点検より後に次のどれかが起きたら、トップの「今日のアクション」に点検を促す行を出す
  - 「防」が新しく点いた (前回の点検の時点で点いていなかった銘柄)
  - 損切り幅を超えたロットが増えた (前回の点検に無かったロット)
  - 市場ステートが悪化した (前回の日付以前の最新のログより悪い日がある)
  - 推定維持率が下がった (適正エリアより多いに変わった、または 10 ポイント以上低い)
- **損切り幅と時間軸はロット単位で見る**。そのロットの戦略の幅と建単価で比べる
- **「持つ」には理由と、売る条件を1つ必須にする**。売る条件は「価格の線 / 維持率で売る順番 / 次の決算で判断 / 期限」から選ぶ。価格の線の引き直しが2回目以降なら、期限も必須
- **毎回、推定維持率が何%を割ったらどの銘柄をどの順で売るかを決めて保存する**
- 線を割った建玉の問いは、投資戦略.md の「ファンダで買い、値段で降りる」に従って「全部売る / 半分売る / 持つ (ルールの例外)」で聞く
- 次の点検で、前回の決定を約定・終値・日次ログで照合し、実行すべきだった約束のうち実行された割合を出す。月次の振り返りの §0 がこれを引く
- 台帳の仮説は、点検の中では更新日と直近の決算の比較だけを見る。問いの材料には台帳の文言を引くだけにし、一次資料での精査は別のフローにする

## Rationale

| 採用しなかった案 | 理由 |
|---|---|
| 毎週の定期実行 | 本人の見立てでは、毎週は続かない。点検が要るのは相場のイベントが起きたとき・起きそうなときで、平時は要らない。崩れ始めた10月末のような局面で早く気づくことが目的 |
| 「持つ」に価格の線を必須にする | 大きく売られた位置から戦略の幅で線を引き直すと、取得値から −60% 前後まで許す線になる銘柄があった (11/15 の仕分け)。その局面で守る線は推定維持率だった |
| 「防」の初点灯日を前回の日付と比べる | 初点灯日は今の戦略での最初の日なので、一度消えて点き直した銘柄を拾えない。前回の点検の時点で点いていた銘柄の集合と比べる。前回に点いていて、その後に消えてまた点いた銘柄は拾わない (前回に扱いを決めており、約束の照合で見えるため) |
| エピソード単位で幅超えを見る (月次と同じ) | ロットに別の戦略が付くと判定しない。10月の半導体のブレイクで買い増したロットは、こちらで漏れていた |
| 点検の中で台帳の仮説を決算資料まで精査する | 1回が重くなり、続かない。精査は台帳の更新という別のフローで行い、点検では「いつまでに台帳を見直すか」を期限つきの約束にできる |
| サイズと確信のずれ、売り方の偏り (issue の観点⑤⑥) | 今回の暴落でユーザーが挙げた点 (線を割っても切らなかった、下落中の買い増し、買い増しのロットに損切りを入れなかった) に含まれない。使ってみて要れば足す |

## Consequences

- `$KS_DATA_DIR/portfolio_review/YYYY-MM-DD.{json,md}` が、点検の決定 (1銘柄ごとの扱い・売る条件・維持率で売る順番) の唯一の記録になる。既にあれば書かない。Drive への複製に含める
- 約束した価格の線は、Shintakane の「防」の判定には入らない (損切りラインは約定と戦略の幅から計算する)。線を割っても日次では知らせず、次の点検で照合する
- 逆指値が入っているかは Shintakane から見えないので、点検の問いで自己申告で聞く
- 再検討の条件:
  - 点検の約束の履行率が低いまま2回続いたら、約束した線を日次の「防」と今日のアクションに繋ぐ (#589 Phase 2)
  - きっかけの行が平時にも出続けて無視されるようなら、きっかけの条件を絞る
  - トップの表示でロット単位の幅超えの計算が1秒を超えたら、日次バッチで計算してファイルに置く
