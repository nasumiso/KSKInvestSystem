# 防衛線は既存の「早売」ルールで判定し、損切り線はエピソード単位で出す

- Status: Accepted
- Date: 2026-08-11 (2026-09-03 に損切り線の単位を追記)
- Related: #386, #428, #438

## Context

保有銘柄の出口を戦略ごとに事前に決め、終値が防衛線を割れた事実を日次で見逃さないようにしたい (半導体銘柄を持ち続けて急落を被った反省)。
issue 本文は「終値で2営業日連続MA割れ」「中長期ファンダは40WMA」「現物のみ」を想定していたが、実データと合わない点があった。

## Decision

- **MA割れ判定は既存の「早売」ルール (Morales/Kacher の violation / porosity + A日安値割れで確定) を窓だけ変えて使う**。10MA が「早売」、戦略ごとの 50MA / 30WMA / 40WMA が「防」で、同じ考え方の別窓とする
- 中長期ファンダの MA 防衛線は **40WMA**
- 対象は **現物 + 信用買建** を統合した銘柄単位のポジション (売建は対象外)
- **損切り線は fill から再計算する (ラチェット)**。保存するのは「防が発動した事実」だけ
- **損切り線の入力はエピソード (建玉ラウンド) 単位**。保有サイクル全体の fill をまとめて入れない

## Rationale

採用しなかった案:

- **2営業日連続割れ** — 既存の violation ルールの方が shakeout に強く、早売と防で判断基準がぶれない
- **中長期ファンダの防衛線を「ステージ2コア毀損」にする** — ユーザー自身の出口ルールに近いが、全戦略を「MA + violation」という単一の枠組みに揃えるシンプルさを優先した。ステージ2コアは trend_template 列で別途見える
- **現物のみ対象** — 1保の約6割が信用建玉で、保有の大半が無防備になる
- **損切り線を保有サイクル単位で出す** — 3496 で、1年半前に決済済みの高値建玉の線がラチェットで残り続け、+12% の建玉に「防」が出た。保有株数が0にならないとサイクルが切れないため、旧トレードの原価を引きずる

## Consequences

- 不変条件: 全銘柄で「損切り線 ≤ 取得単価」が成り立つ
- 防歴の同一性 (`cycle_id`) は保有サイクル単位のまま。現引をまたいでも防歴は維持される
- 戦略マスターの `exit_rule` が防衛線の定義元になる。戦略を追加したら exit_rule も要る
- 「防予」(割れたが未確定) は1日で消えるため見逃しやすく、優先度を下げた
