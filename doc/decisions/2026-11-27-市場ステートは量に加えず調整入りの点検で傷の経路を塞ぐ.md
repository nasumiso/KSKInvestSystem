# 市場ステートは量に加えず、調整入りの点検で傷が広がる経路を塞ぐ

- Status: Accepted
- Date: 2026-11-27
- Related: #589、#610、[資金管理の検証](../投資メモ分析/レビュー/資金管理の検証_2026-11.md) の 6、[市場ステート仕様](../spec/市場ステート仕様.md)、[2026-11-22 の判断](2026-11-22-保有の点検は日を決めずきっかけで起こし持つには売る条件を約束させる.md)、[.claude/skills/portfolio-review/SKILL.md](../../.claude/skills/portfolio-review/SKILL.md)

## Context

「市場ステートを量の決定に使わない」は、状態どおりに持ち高を変えるとリターンの大半を失う (日経225 で年率 +6.9% → +2.9%) という 2026-11-15 の検証が根拠だった。#610 で日経VI の上限が一度も発動していなかったと分かり、過去の「効かなかった」を洗い直した。市場ステートの検証は、調整で 0%にする極端な案を、平均倍率の違う一定 100% と比べたものだった。

測り直すと、調整で 0.8倍まで抑える版は、平均倍率の近い一定 1.0倍より年率・最悪の1か月が良く、日経VI に重ねると VI の弱いすぐ戻る急落 (コロナ・関税型) で傷が浅くなった。ただし作り直した市場ステートは本番より調整入りが数日早く、1週遅らせると年率が VI だけより 0.5pt 低くなった。

## Decision

- 市場ステートは運用総額の目標に加えない (表示と日次ログに残す)
- 保有額で加重した市場ステートが前回の点検より悪化したら保有の点検を促す (#589 のまま)。**調整に入ったときは「調整入りの点検」も行う**
  1. 逆指値が全部の建玉に入っているか (前回以降の買い増しのロットは名前を挙げて聞く)
  2. 線に近い玉を、割ったらどうするかを割る前に決める
  3. 調整が解けるまで、新しい買いをどう絞るかを約束する (`buy_limits`: 買い増ししない / 新規は幅の狭い戦略だけ / 新規は小さめ / 絞らない)。次の点検で、前回以降の新規建て・買い増しと照らし合わせる
  4. 維持率で売る順番を今の保有で引き直す
- 保有銘柄タブのポジション管理ルールに1行で出す

## Rationale

| 採用しなかった案 | 理由 |
|---|---|
| 調整のあいだ 0.8倍までに抑える (日経VI に重ねる) | すぐ戻る急落の傷は浅くなるが、本番の遅れを見込むと年率で 0.5pt ほど払う。売買の手数料・税金は入れておらず、調整は期間の約3割あるので、実際の負担はもっと大きい。効果の大きさが切り替わりの数日で変わり、本番との一致を確かめた切り替わりは1回だけ。下げが長く続く暴落は VI と口座の上限で受け持っており、すぐ戻る急落は致命傷になりにくい |
| 調整入りを今日のアクションで目立たせる (色・先頭) | 今の点検のきっかけ (1段の悪化でも出る) が平時に無視されるようになってから考える (2026-11-22 の判断の見直し条件) |

今回の暴落で傷を深くしたのは、損切り幅を超えた玉の持ち越し・買い増したロットの逆指値の漏れ・下落中の買い増しだった (2026-11-22 の判断の Context)。量を機械的に減らす代わりに、この経路を調整入りの時点で塞ぐ。

## Consequences

- 量の決定の材料は、口座の資産・信用評価損益率・日経VI の3つのまま
- 「新しい買いの約束」は Shintakane の日次の判定には入らず、次の点検で照合するだけ
- 見直す条件: 日次ログの市場ステートが半年ほどたまったら、作り直し (`money_rule_sim.py` の `replay_market_state`) との一致を長い期間で確かめ、売買のコストを入れても急落の守りが残るかを測り直す。点検の約束 (`buy_limits`) が守られない回が続いたら、量で縛る案を再検討する
