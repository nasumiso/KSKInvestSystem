# 運用比率の目標は、感情スコアと F&G の逆張りで、推定維持率から出す

- Status: Accepted
- Date: 2026-10-24
- Related: #480、#362、#527、[推定維持率仕様](../spec/推定維持率仕様.md)、[投資戦略.md](../投資戦略.md) の「感情スコアとレバレッジ」

## Context

#362 の運用比率ガイドは「保有額 ÷ 基準運用額 2,650万」を市場ステート (順張り) のレンジと比べ、「恐怖側での自動増枠はしない」と決めていた。仕様レビュー_0927 で、表示はできているが行動につながっていないと評価した。出発点だった投資メモの感情スコアシートは「感情と逆向きにレバを決める」(恐怖で張り、熱狂で落とす) もので、#362 はそこから向きが変わっていた。基準運用額はユーザーが宣言する値で、損益で実態とずれていく。

#527 で楽天・SBI の推定維持率が出せるようになり、実際の制約 (追証) を物差しにできるようになった。

## Decision

- **基準運用額を廃止し、推定維持率を物差しにする**。シートの「資産比」の資産は証券口座の自己資本とみなし、シートの % (自己資本 ÷ 建玉) をそのまま目標の維持率として使う
- **#362 の「恐怖側で自動増枠しない」を覆す**。目標の段は感情スコア (自己申告) が主で、日本版 F&G が Extreme (< 25 / ≥ 75) なら逆張りで 1 段ずらす
- F&G が Extreme でない日は、市場ステートで攻める側に上限をかける (調整局面 0 段・上昇圧力下 −1 段まで)。ExFear・ExGreed では逆張り、それ以外は順張り気味、というユーザーの方針に合わせる
- 感情に関係なく、全保有が一律に 20% 下がっても追証にならない量で頭打ちにする
- 運用総額のバーは残し、適正エリアを「受入保証金 ÷ 目標維持率」から出した運用総額に置き換える

## Rationale

| 採用しなかった案 | 理由 |
|---|---|
| 基準運用額のまま感情スコアを足す (#480 の案 A〜D) | 基準運用額が自己資本とずれる問題が残る。10/23 は基準運用額で 0.87倍、口座の自己資本では 1.92倍で、判定が逆になっていた |
| 感情スコアだけで決め、市場ステートは参考 | 自己申告は甘くなる (過信の人は +3 と申告しない)。調整局面の途中で怖いと申告すると建て増しを勧め、順張りのエントリー・出口ラインとかみ合わない |
| 3×7 の表を事前に宣言 (案 D) | F&G も入れると 3×7×3 になり、事前に宣言するには大きすぎる |
| 追証の下限を厳しくする (保有の下落を日経の 1.5倍とみなす) | ユーザー判断で見送り。一律下落の前提なので、実際の余裕は数字より薄い |
| 恐怖側に増えた余地に条件 (指値・分割・Active 銘柄) を付ける | ユーザー判断で見送り |

## Consequences

- 自己申告の甘さへの対策は、F&G の Extreme と市場ステートの上限だけ。行動 (直近の売買額・新規建て数) と入力の突き合わせ (#480 やりたいこと 3) は、記録が貯まったら最初に扱う
- 推定維持率の基準値 (保証金率) が古いと、適正エリアもずれる。楽天・SBI のどちらかが推定できない日は適正エリアを出さない
- **見直しの条件**: 2026-12 末の仕様レビューで、日次ログ (`exposure_log.json`) から「F&G が Extreme の日・感情スコアが 0 以外の日に、運用総額が適正エリアの方向へ動いたか」を見る。動いていなければ、表示ではなく仕組みを見直す
