# 運用総額は、ふだん一定の倍率に口座の上限をかけ、信用の底でだけ買い向かう

- Status: Accepted
- Date: 2026-11-26
- Related: #594、#593、[資金管理の検証](../投資メモ分析/レビュー/資金管理の検証_2026-11.md)、[投資戦略.md](../投資戦略.md) の「張りたい量」「張れる量」、[2026-10-24 の判断](2026-10-24-運用比率の目標は感情スコアとFGの逆張りで推定維持率から出す.md)、[2026-10-28 の判断](2026-10-28-信用評価損益率をFGと重ねない逆張りに加える.md)

## Context

2026年10〜11月の半導体の暴落で、口座は年初来 +90% (6月) から −20% (11/20) になった。旧方式 (感情スコアと F&G・信用の逆張りで目標維持率を決める全域の逆張り) は、恐怖局面で目標を緩め、損切り幅を超えた玉を抱えたまま「適正エリアの内側」と出した。11/22 に「通常は順張り、異常 (±3) は逆張り、口座の余裕で上限」に改めたが、数字はすべて仮で、#594 で過去の推移に当てて確かめることにした。第三者レビューで「最も良い数字を探すより、各仕組みを足す必要があるかを確かめる」よう求められた。

## Decision

- **張る量 = ふだん 1.2倍と、口座の上限 (張れる量) の小さい方。** 張れる量は 2.0 × (1 − 口座の高値からの下落率 ÷ 20%)、下限 0.8倍。四半期末に高値をその時点の資産へ置き換える
- **信用評価損益率 (公表値) が −15% 以下で前週より改善したら、3か月だけ 1.6倍まで上げる**。口座の上限が先に効く
- 目標へは週1段 (倍率の順の隣の段) ずつ近づく
- **日本版 F&G と感情スコアは量の計算に使わない。** F&G は表示と日次ログに残し、Extreme Fear は準備の合図、Extreme Greed は保有の点検のきっかけにする。感情スコアは日曜の見直しで週1回記録する
- 過熱で減らす仕組みは持たない

## Rationale

保有の日次リターン (2025-01〜2026-11、約定と終値から復元) に倍率を重ね、仕組みを1つずつ足して比べた。市場全体でも日経平均 (2001〜、信用は 2009〜) で確かめた。

| 採用しなかった案 | 理由 |
|---|---|
| 旧方式 (全域の逆張り) | 全部の版の中で一番悪い。感情を市場に沿って申告したとみなすと、全期間 +18% (一定 1.2倍は +41%)、最大ドローダウン 58%。下げが続く局面で倍率を上げ続けた |
| F&G による平時の順張り (11/22 案の −2〜+2) | 同じ平均倍率で一定に張った場合を超えない。上乗せに見えた分は F&G が3成分しかない期間に限られた |
| 200日線による順張り (日経平均・TOPIX・グロース250) | 指数を替えても一定倍率を超えない。暴落は保有の偏りによる下落で、市場の物差しでは捉えられなかった |
| 過熱 (+3) で 0.8倍に減らす | 過熱の合図のあとも上げが続くことが多く、取り分を失った。最大ドローダウンは変わらない |
| F&G の Extreme Fear で 2.0倍に増やす (11/22 案の −3) | Extreme Fear はパニックの最中に近い。日経VI 40超のあとはさらに平均 −9%・最悪 −38% 下がった。信用の底 (11回中10回が3か月後プラス、さらなる下落は最悪 −8.8%) のほうが合図として優れる |
| 四半期末の置き換えをやめる | 保有の2年分では良く見えたが、日経平均 2009年以降では7割の週で上限に縛られ、年率が 12.3% → 9.1% に落ち、信用の底でも買い向かえなかった |
| 基本の倍率を 1.4・1.6倍に上げる | 上げ相場では高いほど勝つので、過去のデータでは決められない。余力を残して底で拾う前提と、急落の最初の1〜2週の傷を重く見た (ユーザー判断) |

## Consequences

- 量の決定の材料は、口座の資産と信用評価損益率の2つになる。F&G・感情・市場ステートは表示と記録だけ
- 実際の保有に倍率を重ねた評価で、銘柄の入れ替え (底で新しく建てる玉、RS の弱い順に減らす) は再現していない。保有の期間は約23か月で、今回の損失を見て作ったルールを同じ期間で測っている
- 見直す条件: 5成分の F&G と感情スコアの記録がたまったら、順張りと感情の効き目を測り直す。信用の底の合図 (2026-11-20 が最新) のその後を、次の仕様レビューで確かめる。感情を行動のブレーキに使うかは #530 の結果で決める

## 追記: 実装で決めたこと (#593、2026-11-26)

- **物差しは倍率** (運用総額 ÷ 自己資本)。自己資本は推定維持率と同じ推定から、受入保証金 + 0.2 × 代用の現物 + NISA + 信用の評価益 + 保証金の外の現金 として出す。維持率は表示と追証の頭打ちに残す
  - 保証金の外の現金は、保証金率を入れ直すときに一緒に入れる。証券会社の画面と突き合わせたら、SBI では現金の約4割 (預り金・スィープ口座) が保証金の外にあり、これを入れないと自己資本が大きく少なく出た。保証金率の欄に参考委託保証金率 (現金も含めた率) を入れて代える案は、追証までの距離が甘く出るので採らない
- **入出金は取り込まない**。保証金率を入れ直したとき、同じ建玉・終値で旧基準値と新基準値の自己資本の差 (`equity_gap`) を残し、下落率の高値を同じ額だけずらす。手数料・金利も一緒に外れるが小さいので受け入れる。入出金履歴の定期的な取り込みは却下 (手間を増やさない)
- **今週の目標は先週の目標から1段**動かす。実際の倍率から動かすと、目標を守らなかった週に目標まで動いてしまい、#594 の検証と決まり方がずれるため。初回は反映した日の実際の倍率以下の段を張れる量で頭打ちにする
- 買い向かいは最後の合図から3か月 (合図が続けば延びる)。合図のあとに信用評価損益率が再び悪化しても取り消さない (#594 と同じ。取り消しの効果は検証していない)
