# 売買エピソードのチャートはラウンド単位の別チャートにする

- Status: Accepted
- Date: 2026-09-28
- Related: #366, PR #442

## Context

売買履歴で、建玉ラウンドごとに「どんな形で建て、売った後どう動いたか」を図で振り返りたい。当初案は stock ページの詳細チャートに IN/OUT マーカーを置くことだった。

## Decision

- 売買履歴のエピソード展開行に、**そのラウンド専用の週足チャート**を新設する (詳細チャートには載せない)
- 表示窓はラウンド基準の可変窓 (建て〜決済の前後4週)
- 週足は yfinance 週足キャッシュから読む。**WebApp はネットワークアクセスしない**
- マーカーは fill を (約定日, 売買方向) でまとめて打つ。`round_trips` は使わない
- (2026-09-30 追記) マーカー間を往復行 (`build_round_trips`) ごとに建て→決済の点線で結び、明細の往復行にカーソルを乗せると対応する線を強調する。マーカーは往復行を使わないが、線は明細行と1対1に対応させるため往復行を使う (信用は建約定日、現物は FIFO。信用返済の 22% は建約定日が FIFO と一致しないので、信用を FIFO で組むと実際の対応と食い違う)
- (2026-10-03 追記) エピソードの戦略の出口ルールから、防衛線 (移動平均線と損切りライン) を重ねる。日足の線 (50日線) は 10週線で近似する (日足キャッシュは直近3か月しか無く、過去のラウンドでは計算できない)。損切りラインは平均取得単価から引くので、買い増しのたびに動く階段になる。ルールは今の戦略マスターのもので、当時のルールではない。空売り・期首持越し・未分類・価格軸が揃わないラウンドには出さない。往復行の線 (画面上の名前は「売買の線」) と防衛線は画面で別々に切り替えられる (全チャート共通、ブラウザに保存)。売買の線は売買がひと目で分かるので既定で出す。防衛線は重ねるとごちゃつくので既定は隠し、振り返りで見たいときに出す
- 分割・併合の未換算は補正しない。約定価格が週足終値から 1.5 倍以上外れる点は打たずに注記する
- SVG は初回展開時に fetch する (初期HTMLに埋めない)

## Rationale

- 詳細チャートは RS 軸で約定価格を乗せられず、銘柄あたり1枚しか置けない (6227 は closed 12 + open 1 で重なって読めない)
- 固定窓 (`_SPARK_LOOKBACK=20`) では保有 p90=17.6週を賄えない。DB の `price_week_log` は25週で足りず、キャッシュは約105週ある
- `round_trips` は FIFO で1本の売りを複数ロットに割るため、同じ座標にマーカーが重なる
- `tate_price` は SBI に無く、保有中エピソードには返済 fill 自体が無いので、補正は一部しか救えず新たな誤りを生む
- 431ラウンド分の SVG を初期HTMLに埋めると、#406 の初期HTML削減と矛盾する

## Consequences

- 週足キャッシュが無い・古い銘柄はチャートを描かず説明文に縮退する
- 分割・併合をまたぐラウンドでは一部のマーカーが欠ける (注記で知らせる)
