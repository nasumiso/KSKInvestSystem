# 日本版 Fear & Greed 仕様

CNN Fear & Greed Index の構造 (成分の等ウェイト平均・5段階の rating) に寄せた、日本市場のセンチメント指数。
計算は `scripts/fear_greed_jp.py`、取得と保存は `shintakane.update_fear_greed_jp()` (日次バッチ)、出力は `code_rank_data/fear_greed_jp.json`。
運用比率ガイドでは **75 以上 (Extreme Greed) のときに上限を削る**方向にだけ使う ([コマンド一覧](コマンド一覧.md) の運用比率ガイド)。

## 共通

- 各成分は、直近2年 (約490営業日) の履歴に対する percentile rank で 0〜100 にする。min-max は外れ値1点でレンジが潰れるので使わない
- 合成スコアは、取れた成分の単純平均。取れない成分は平均から外す (欠けたまま保存した日は翌日のバッチで取り直す)
- rating: 25 未満 Extreme Fear / 45 未満 Fear / 55 未満 Neutral / 75 未満 Greed / それ以上 Extreme Greed

## 成分

| 成分 | CNN 原典 | 日本版 | データ源 | 原典との差分 |
|---|---|---|---|---|
| モメンタム | S&P500 と 125日移動平均の乖離 | 日経225 と 125日移動平均の乖離率 | nikkei225jp `daily2year.json` 列[1] | 指数が違うだけ |
| 新高値強さ | NYSE の52週高値 − 52週安値 | 東証プライムの年初来高値 − 年初来安値の銘柄数 | 同 列[8][9] | 52週ではなく年初来 (データ源の都合) |
| 騰落ブレッドス | McClellan Volume Summation Index | 東証プライム 騰落の McClellan Summation Index | 同 列[5][6] (値上がり・値下がり銘柄数) | 出来高ではなく**銘柄数**ベース。差は ratio-adjusted ((上がり−下がり)/(上がり+下がり)×1000) |
| ボラティリティ | VIX と その50日移動平均の比較 | 日経VI の値そのもの (高いほど Fear なので反転) | nikkei225jp `SL161_1990.json` | 50日平均との比較をしていない (#524 で検討中) |

### 騰落ブレッドス (2026-10 に累積型へ変更, #524)

- Oscillator = 差の19日 EMA − 39日 EMA (原典の 10% / 5% 平滑)、Summation Index = Oscillator の累積
- EMA の初期値は先頭の差。初期値の影響が残る先頭120本 (約半年) は正規化の履歴に使わない。`daily2year.json` は約2年分なので、percentile の履歴は約1年半になる
- `daily2year.json` は日々先頭が1行落ちるので累積の起点も動くが、立ち上がりを外したあとは列全体が定数ずれるだけで percentile は変わらない
- 変更前は**その日1日の (値上がり − 値下がり)** を percentile にしていたため、1日の急落で Extreme Fear まで落ちていた。累積型では1日分の Oscillator しか動かない
- `daily2year.json` の列[19]〜[24] は値上がり・値下がり・変わらずの出来高 (か売買代金) とその比率らしいが、何の値か未確認。確認できたら出来高ベースに切り替える
- 新旧の比較は `python fear_greed_jp.py compare`

## 入れていない成分 (2026-10-20 調査, #524)

| 成分 (CNN) | 取れるもの | 状態 |
|---|---|---|
| 安全資産の需要 (株と債券の20日騰落率の差) | 財務省「国債金利情報」CSV (`jgbcm.csv` 当月 / `data/jgbcm_all.csv` 1974年〜)。10年金利が日次 (翌営業日11時頃更新) | 取れる。債券の騰落率は10年金利の変化から近似する。次に入れる候補 |
| プット・コール比率 (5日平均) | JPX「当日取引高等」の日次 Excel に日経225オプションのプット・コール別取引高・建玉 | 当日分しか置かれていない。毎日取って貯める仕組みが要る |
| ジャンク債の需要 | 日本にハイイールド債市場がほぼ無い。日証協の格付け別社債スプレッドか、米国の FRED `BAMLH0A0HYM2` で代用 | 入れない可能性が高い |
