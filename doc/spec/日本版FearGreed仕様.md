# 日本版 Fear & Greed 仕様

CNN Fear & Greed Index の構造 (成分の等ウェイト平均・5段階の rating) に寄せた、日本市場のセンチメント指数。
計算は `scripts/fear_greed_jp.py`、取得と保存は `shintakane.update_fear_greed_jp()` (日次バッチ)、出力は `code_rank_data/fear_greed_jp.json`。
運用比率ガイドでは **75 以上 (Extreme Greed) のときに上限を削る**方向にだけ使う ([コマンド一覧](コマンド一覧.md) の運用比率ガイド)。

## 共通

- 各成分は、直近2年 (約490営業日) の履歴に対する percentile rank で 0〜100 にする。min-max は外れ値1点でレンジが潰れるので使わない
- 合成スコアは、取れた成分の単純平均。取れない成分は平均から外す (欠けたまま保存した日は、次のバッチで取り直す)
- rating: 25 未満 Extreme Fear / 45 未満 Fear / 55 未満 Neutral / 75 未満 Greed / それ以上 Extreme Greed
- 新旧の比較は `python fear_greed_jp.py compare` ([コマンド一覧](コマンド一覧.md))

| 騰落ブレッドス | McClellan Volume Summation Index | 東証プライム 騰落の McClellan Summation Index | 同 列[5][6] | 同上 | 出来高ではなく**銘柄数**ベース |

### 騰落ブレッドス (2026-10 に累積型へ変更, #524)

- 差 = (値上がり − 値下がり) / (値上がり + 値下がり) × 1000 (ratio-adjusted)。東証プライムの銘柄数の増減で水準がずれないようにする
- Oscillator = 差の19日 EMA − 39日 EMA (原典の 10% / 5% 平滑)、Summation Index = Oscillator の累積
- EMA の初期値は先頭の差。初期値の影響が残る先頭120本 (約半年) は正規化の履歴に使わない。`daily2year.json` は約2年分なので、percentile の履歴は約1年半になる
- `daily2year.json` は日々先頭が1行落ちるので累積の起点も動くが、立ち上がりを外したあとは列全体が定数ずれるだけで percentile は変わらない
- 変更前は**その日1日の (値上がり − 値下がり)** を percentile にしていたため、1日の急落で Extreme Fear まで落ちていた
- `daily2year.json` の列[19]〜[24] は値上がり・値下がり・変わらずの出来高 (か売買代金) とその比率らしいが、何の値か未確認。確認できたら出来高ベースに切り替える

### ボラティリティ (2026-10 に50日平均との比較へ変更, #524)

- 乖離率 = (VI / 直近50日の単純移動平均 − 1) × 100。高いほど Fear なので反転する
- 変更前は VI の水準そのものを percentile にしていた。VI は局面によって何ヶ月も高止まりするので、水準だと Fear が続きやすい
- 画面の「元データの値」は VI そのもの (スコアは乖離率から出す)

### 安全資産の需要 (2026-10 に追加, #524)

- 株の騰落率 = 日経225 の20営業日前からの騰落率 (%)。債券の騰落率 ≈ −9 × 10年金利の20営業日前からの変化 (%pt)
- 株価と金利の両方がある日だけで20営業日を数える
- 財務省 CSV は Shift-JIS。1行目がタイトル、2行目がヘッダ (`基準日,1年,…,10年,…`)、日付は和暦 (`R6.10.1`)、欠損は `-`。英語版のヘッダ (`Date,…,10Y`) と西暦の日付も読める

## 入れていない成分 (2026-10 調査, #524)

| 成分 (CNN) | 取れるもの | 判断 |
|---|---|---|
| プット・コール比率 (5日平均) | JPX「当日取引高等」の日次 Excel (`YYYYMMDDopen_interest.xlsx`) に日経225オプションのプット・コール別の取引高・建玉 | **見送り**。当日分しか置かれず (過去日の URL は 404)、毎日取って貯める仕組みが要る。2年の percentile が効くまで2年かかる。過去分を月間統計 (PDF) から埋められるかは未確認 |
| ジャンク債の需要 | 日本にハイイールド債市場がほぼ無い。日証協の格付け別社債スプレッドか、米国の FRED `BAMLH0A0HYM2` で代用 | **入れない**。前者は作るのが重く、後者は米国の指標で日本版の意味が薄れる |
