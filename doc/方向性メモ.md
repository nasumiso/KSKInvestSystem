# Shintakane 方向性メモ
## AI時代の「半裁量クォンツ」としての個人投資OS

### 1. 基本方針
Shintakaneが目指すべき方向は、完全自動売買のクォンツではなく、**人間の中期ファンダ判断を支援する半裁量クォンツ**である。  
より正確には、Shintakaneは「AIで銘柄を当てるシステム」ではなく、**AIで自分の投資判断をファンドマネージャー化するシステム**を目指す。

AI時代には、決算資料の要約、定量スクリーニング、株価・出来高の監視、ニュース抽出、指標比較といった作業は急速にコモディティ化する。  
そのため、Shintakane単体の機能やコードそのものは、長期的な堀にはなりにくい。

本質的価値は、以下が結合することにある。

- Shintakaneによる継続監視
- コウスケ自身の銘柄解釈
- AIを使った反証
- 売買ログ
- 見送りログ
- ポジション管理
- 自分の失敗パターンの記録
- 中期ファンダ＋モメンタム補助という投資スタイル

つまり、Shintakaneの価値は「市場を直接予測する力」よりも、**自分の判断を壊さない力、再現性を上げる力、見送る力**にある。

---

### 2. なぜ完全自動売買ではなく半裁量なのか
多くのAI投資活用は、定量データからの自動売買、従来のシステムトレードの延長に向かいやすい。  
理由は、バックテスト、勝率、損益、シャープレシオなどで成果を測りやすく、構造化データだけで実装しやすいからである。

しかし、この領域は最終的にAI同士・機関同士の戦いになりやすい。  
機関投資家は、データ量、執行速度、研究体制、資金量、取引コスト、リスク管理の面で個人より圧倒的に強い。

一方、半裁量クォンツは個人に向いている。

| 観点 | 完全自動売買AI | 半裁量クォンツ |
|---|---|---|
| 競争相手 | 機関・HFT・クォンツ | 自分の判断ミス、他の個人 |
| 優位性 | モデル精度・速度 | 解釈・時間軸・規律 |
| データ | 構造化データ中心 | 構造化＋非構造化＋自分の履歴 |
| 検証 | しやすいが過剰最適化しやすい | 難しいが実戦に近い |
| 模倣リスク | 高い | 個人最適化されるほど低い |

AI時代に個人が勝つには、人間を排除するより、**人間の弱点を補正する方が現実的**である。

この分業を支える知見:

- カーネマン: **「機械的スクリーニング → 人間が最終判断」が、純粋な人間判断・純粋なシステム判断のどちらも上回る**
- アルファディケイの影響を受けにくい: 優位性の源泉が人間の定性判断 (模倣しにくい部分) にあるため、AI による発見と消滅のサイクルから守られる  
Shintakaneは「人間を消す」のではなく、**自分を増幅しつつ、自分を縛る**システムであるべき。

### 3. 相場におけるAIの位置づけ
チェス・将棋・囲碁では、AIは人間を大きく超えている。  
そのため、投資でも「人間が理解する必要はなく、完全AI判断が最善ではないか」という問いが出る。

ただし、相場はボードゲームと違い、開いた複雑系である。  
制度、参加者、金利、政策、地政学、需給、投資家心理が変化し続ける。  
また、投資の最善手は、資金量、時間軸、生活費、最大許容損失、税金、精神的耐性、流動性によって変わる。

したがって、相場におけるAIの役割は、全員に共通する唯一の最善手を出すことではない。  
**自分の制約条件に合った最善手を出すこと**である。

Shintakaneでは、AIに局面評価をさせる。  
人間は、目的・制約・リスク許容・時間軸を設計する。  
そのうえで、買う、見送る、待つ、減らす、持つという判断の質を上げる。

### 4. Shintakaneの中核思想
Shintakaneは、銘柄発掘ツールでも、ランキング生成機でも、万能予測AIでもない。  
目指すべき姿は、**個人ファンド運営システム**である。

管理すべき投資判断のライフサイクルは以下。

1. 銘柄発見
2. 定量評価
3. 定性仮説
4. 未織り込み材料の整理
5. 反証
6. 地合い・需給・チャート確認
7. 自分のスタイル適合判定
8. ポジションサイズ決定
9. 決算・IR・株価反応の継続監視
10. 売却・保留・買い増し判断
11. 失敗ログ化
12. 見送り判断の検証

重要なのは、Shintakaneを「買う銘柄を増やす装置」にしないこと。  
むしろ、**買わない銘柄を増やす装置**として設計する。

AIとシステムによって情報量が増えると、優位性が増えたように錯覚しやすい。  
しかし、分析量や美しいダッシュボードはリターンを保証しない。  
Shintakaneは、情報を増やすだけではなく、**絞る・止める・待つ・記録する**ためのシステムであるべき。

### 5. 実装上の中核機能
Shintakaneに優先的に持たせたい機能は以下。

| 機能 | 目的 |
|---|---|
| 変化検知 | 業績・株価・出来高・IR文脈の変化を拾う |
| 仮説管理 | なぜ監視しているのかを失わない |
| 反証生成 | 買いたい理由の逆側を必ず見る |
| 見送りログ | 買わなかった判断も資産化する |
| ポジション設計 | 期待値ではなく失敗時損失からサイズを決める |
| 決算後レビュー | PTS・翌日・1週間後の反応を分けて見る |
| スタイル適合スコア | 自分の勝ちパターンに合うか判定する |
| ミス分類 | 損失を銘柄ミス、タイミングミス、サイズミス等に分ける |
| 仮説崩壊条件 | どこで見立てが間違いになるかを事前に決める |
| ウォッチ銘柄の育成履歴 | 銘柄理解の積み上がりを保持する |

特に重要なのは、**見送りログ**である。  
多くの投資家は買った銘柄しか検証しない。  
しかし、投資判断の質は「買った銘柄」「買わなかった銘柄」「売った銘柄」「売らずに持った銘柄」すべてに現れる。

### 6. 価値測定KPI
Shintakaneの価値は、短期リターンだけで測るべきではない。  
短期損益は地合いと運に大きく左右される。

まず測るべきKPIは以下。

| KPI | 見たいもの |
|---|---|
| ウォッチ銘柄からの上昇捕捉率 | 上がる銘柄を事前に見ていたか |
| 買わなかった好機の記録 | なぜ買えなかったか |
| 買った銘柄の事前スコア | 高スコアほど成績が良いか |
| 決算後反応の予測精度 | PTS・翌日・1週間後の方向性 |
| 損切りルール遵守率 | システムが規律を守らせたか |
| 早売り防止率 | 売らずに持つ根拠を出せたか |
| ポジションサイズ妥当性 | 大きく張った銘柄ほど期待値があったか |
| 見送り銘柄のその後 | 見送り判断が正しかったか |
| AI分析後の売買成績 | AI利用が本当に改善したか |
| 精神的な焦りの減少 | 今日見るべきものが明確になったか |

特に重要なのは、売買ミスの再発が減ったか、ポジションサイズが改善したか、見送り理由が後から検証できるかである。  
投資を本業寄りにするなら、メンタルの安定もリターンの一部である。

### 7. 避けるべき方向
以下の方向に進むと、AI時代には優位性が薄くなりやすい。

- 万能銘柄発掘AI
- 自動で儲かるランキング
- 指標を大量に並べるだけのダッシュボード
- 完全自動売買への過度な寄せ
- バックテスト最適化だけに依存する戦略
- AI分析量を増やして安心する運用
- 買いシグナルを増やす仕組み
- 銘柄候補を増やすだけの仕組み

ランキングは便利だが、ランキング上位を機械的に買うだけでは真似されやすい。  
価値があるのは、以下までセットで残すことである。

- なぜこの銘柄は上位なのか
- でもなぜ買わないのか
- 買うならどの条件か
- どこで仮説が崩れるか
- どの時間軸で見るか
- どれくらいのサイズなら許容できるか

### 8. Shintakaneの勝ち筋
Shintakaneの勝ち筋は、機関投資家と同じ土俵に乗らないことにある。

| 機関が強い領域 | 個人が狙うべき領域 |
|---|---|
| 高頻度売買 | 中期の歪み |
| 大型株 | 小型・中小型 |
| 完全定量 | 定量＋定性 |
| ニュース即時反応 | 数日〜数ヶ月の再評価 |
| 大量分散 | 少数集中＋監視 |
| 決算直後反応 | 決算後の見直し遅れ |
| グローバル標準データ | 日本語ローカル情報・補足IR |

この土俵で具体的にどう見るか (PTS と場中の反応の区別、決算直後の飛びつき警戒 等) は [投資戦略.md](投資戦略.md) の「重視する見方」にまとめる。

これは単なるAI投資ではなく、**自分という投資家を運用するAIシステム**である。

---

### 9. 最終定義
Shintakaneの目標を一文で定義すると、以下になる。

> **AIで銘柄を当てるのではなく、AIで自分の投資判断をファンドマネージャー化するシステム。**

あるいは、より実装寄りに言えば、

> **定量・定性・ポートフォリオ管理・売買ログ・見送りログ・反証・スタイル適合判定を統合し、自分にとっての最善手を出す個人投資OS。**

Shintakaneが守るべきものは、リターンだけではない。  
**判断の再現性、ミスの減少、余計な焦りの抑制、自分の投資スタイルの維持**である。

その積み重ねが、AI時代における個人投資家の本当の優位性になる。
